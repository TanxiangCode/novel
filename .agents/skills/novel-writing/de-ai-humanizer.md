# 去AI味润色与质检规则

## 使用场景

正文生成后、归档前执行。逐句逐段扫描，命中高危项必须无条件改写为具体物理反应或直接删除。

---

## 一、绝对禁用清单（🔴 命中即判为机味，强制删除或改写）

### 1. 套路化微表情与肌肉反应（🔴 强制删除）
- **严禁词条**：
  - `嘴角勾起一抹……`、`嘴角微微上扬`、`嘴角勾起一丝玩味的笑容`、`泛起一丝冷笑`
  - `眼中闪过一丝……`（精芒/杀意/凝重/冰冷/嘲弄/诧异）
  - `倒吸一口凉气`、`深吸一口气`、`倒抽一口冷气`
  - `眉头微皱`、`眉头紧锁`、`眉头一挑`
  - `冷哼一声`、`闷哼一声`、`不由得一愣`
  - `瞳孔猛然收缩`、`瞳孔地震`、`目瞪口呆`
  - `脸色阴沉得能滴出水来`、`脸色青一阵白一阵`
- **物理化改写方案**：
  - 用**眼部视线落点**替代：视线落在对方咽喉、看向门外、盯着地上的碎瓷片；
  - 用**重心与肢体反应**替代：身体重心后撤半步、下颌骨绷紧、喉结滚动、手指抠紧刀柄缠绳。

### 2. 抽象心理声明（🔴 强制删除）
- **严禁词条**：
  - `心中涌起一股……`（暖流/怒火/寒意/无力感）
  - `感到无比愤怒/绝望/欣慰/震惊`
  - `他的内心充满了……`、`掀起了惊涛骇浪`
  - `感到前所未有的压力`、`心提到了嗓子眼`
  - `头皮发麻`、`一股寒意从脚底直冲天灵盖`、`后背瞬间被冷汗浸透`
- **物理化改写方案**：
  - 删除所有心理形容词，仅描写肌肉张力、呼吸粗细、手指与器物的触感反应。
  - *机味*：他心中涌起一股强烈的杀意。
  - *人类*：他手腕一沉，刀尖划过地面碎石，发出刺耳的刮擦声。

### 3. 套路过渡与全知上帝旁白（🔴 强制删除）
- **严禁词条**：
  - `仿佛/宛如/好像/犹如`（机械比喻）
  - `在那一刻`、`一时间`、`不知不觉`、`猛然间`、`陡然`、`刹那间`、`下一秒`
  - `只见`、`紧接着`、`与此同时`、`殊不知`
  - `隐隐约约`、`不约而同`、`仿佛整个世界都安静了`
  - `空气中弥漫着一种……的味道`、`殊不知这一幕彻底改变了……`（上帝剧透）
- **物理化改写方案**：
  - 直接删去无意义过渡词，靠动作的先后顺序自然推进时间；
  - 严格限制在角色当前视线与认知范围内，严禁跳出视角做上帝评述。

### 4. 二分与议论句式（🔴 强制删除）
- **严禁词条**：
  - `不是A，而是B`
  - `这不仅是A，更是B`
  - `与其说A，不如说B`
  - `与其坐以待毙，不如主动出击`
- **改写方案**：
  - 删掉前半句的否定与议论，直接写出客观事实 B。
  - *机味*：这不仅仅是一把剑，更是他复仇的决心。
  - *人类*：他把长剑横在膝头，用粗布擦拭剑刃上的血痕。

### 4.5 解说员句式（🔴 强制删除 · 2026-10-10 新增）

**定义**：跳出角色视角、直接向读者解释或评论的叙述方式。表面是角色内心，实则在向读者解释设定、交代逻辑、评论情节。

**显性解说员句式**（直接禁止）：
- `让我们来看看……`、`值得一提的是……`、`不得不说……`、`也就是说……`、`换句话说……`、`众所周知……`

**隐性解说员句式**（重点清除）：
- **总结式判断**：`这是……唯一的活路`、`不是……是……`、`这是懂行的人……`
- **解释性说明**：`他来自的那个世界，把这叫物理`、`这是'封样印'……`
- **评价性语句**：`他不是没天赋。他是没敢花。`
- **过于工整的比喻**：`练气像挑水……`（带有教学/解释目的的比喻）
- **全知信息**：角色不可能知道的信息，如`老槐的口诀是十年前定下的`
- **戏剧化揭示**：`那一眼看的不是货。是手。`（旁白式悬念制造）

**改写方案**：
- 删除纯解释性语句
- 改写为角色当下的感官体验（视觉、听觉、触觉）
- 保留核心信息，但用角色的方式"想"出来
- 禁止"不是A，是B"的纠正句式（向读者解释）
- 禁止"这是……"的定义句式（向读者科普）

**机味 vs 人类 对比示例**：
- *机味*：`这是陈默唯一的活路。练气六层对九层，退，是一寸寸死；进，才有一寸的乱。`
- *人类*：`练气六层对九层，退，是一寸寸死；进，才有一寸的乱。`

- *机味*：`乱流区。这一带的修士都知道，崖底灵气乱，人掉下去，尸首都找不回来。`
- *人类*：`乱流区。崖底灵气乱，人掉下去，尸首都找不回来。`

- *机味*：`三个月的盘缠，都是为这一趟备下的。今天不成了——不是钱不够，是他已经被算进了另一本册子。`
- *人类*：`三个月的盘缠，都是为这一趟备下的。今天不成了。钱够，但他已经被算进了另一本册子。`

- *机味*：`道理讲完了。讲得通的是他学过的东西——他来自的那个世界，把这叫物理。`
- *人类*：`他学过的东西里，有这个词：物理。`

### 5. 章末感悟式八股总结（🔴 强制删除）
- **严禁词条**：
  - `他终于明白了一切`、`这一刻，他懂得了……`
  - `经历这一切后，他变了`、`他知道，真正的战斗才刚刚开始`
  - `他望着远方，心中已有答案`、`嘴角扬起一抹坚毅的弧度`
- **改写方案**：
  - 章末必须以具体的**物理动作**、**悬念对白**或**突发环境变故**收尾，严禁作者下场替角色总结思想升华。

### 6. 空洞宣传与概括腔（🔴 强制删除）
- **严禁词条**：
  - `前所未有的力量`、`惊天动地`、`毁天灭地`
  - `震撼了整个X界`、`恐怖如斯`、`传说级别的存在`
- **改写方案**：
  - 描写具体的物理破坏效果与环境反馈（如“青石板崩裂三寸”、“震得屋檐瓦片哗啦直落”）。

## 二、句式与语法结构改写标准

| 机味特征 | 问题诊断 | 改写标准 |
|---------|---------|---------|
| **排比三连** | AI 习惯用三个整齐短语造势，学生作文感严重 | 砍掉其中两句，仅保留最具信息量与动作感的一句。 |
| **定语堆砌链** | “深邃幽暗弥漫腐朽气息的地下室” | 切成短句：“地下室很暗，门槛上结着绿霉，有股死鼠味。” |
| **过度解释动机** | 动作后紧跟一句“因为他想……”或心理独白 | 信任读者智商，直接删去动机解释，保留纯动作链条。 |
| **全员论文腔对白** | 乞丐、护卫、魔头都使用标准化书面语 | 执行角色语言锚点：短句、俚语、吞音、粗词、省略句。 |
| **匀速长句流水账** | 连续使用 20–30 字的并列长句，节奏死板 | 执行“断句手术”，将长句切碎为 5–10 字的短句群。 |

---

## 三、润色工作流执行标准

```
1. 【正则扫描】：全局检索并高亮所有高危词（微表情、心理声明、比喻套话、上帝旁白）。
2. 【物理化置换】：将所有抽象形容词和心理声明压缩为具体的肌肉反应、道具交互与五感细节。
3. 【断句手术】：将 20 字以上的长句切分成 2-3 个短句；冲突段落强制压至 10 字以内。
4. 【去标签化与脱水】：删除对话中冗余的“XX沉声道/冷笑道”，改为纯对白或穿插物理动作。
5. 【名字遮盖测试】：隐去所有说话人姓名，仅凭台词风格与动作细节判定角色身份，无法辨认则必须重写台词。
```
