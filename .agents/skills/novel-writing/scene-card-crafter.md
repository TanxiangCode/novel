# 场景卡拆解规范

## 使用场景

章纲确定后、正文生成前执行。将一章（约 3000 字）标准拆解为 **2–3 张场景卡**，单卡对应约 800–1500 字。

**核心铁律**：每张场景卡必须绑定**具体环境道具交互**与**物理生理反馈载体**，杜绝空中楼阁式的假大空对话与心理独白。

---

## 一、场景卡标准模板

```markdown
═══════════════════════════════════════
场景卡 #[N]
═══════════════════════════════════════

【基础信息】
- POV视角角色：[角色名]
- 具体空间与光线/环境：[如：城南同福客栈后院·暴雨夜·檐下挂一盏被风吹得乱晃的死油灯]
- 在场出场人物：[角色 A、角色 B]

【冲突与信息差】
- POV核心即时目标：[POV在本场景最想获取什么/阻止什么]
- 核心物理阻碍/对抗：[具体的人/空间限制/时间倒计时]
- 信息差分布：
  - POV知晓：[信息]
  - 对方知晓：[信息]
  - 双方均未知（隐藏真相）：[信息]
  - 读者知晓（上帝视角）：[信息]

【情绪走向与物理反馈载体】（严禁抽象情绪词，必须指定物理行为）
- 情绪变化曲线：从 [X] 走向 [Y]（如：从警惕试探 → 走向撕破脸皮对峙）
- 绑定的生理/动作载体：[如：视线在门栓停留两次、指节发白、语速放慢半拍、咽口水]

【环境道具交互】（本场景必须出现并发生物理交互的实物）
- 指定道具：[如：一把生锈的火钳、半碗凝了白油的冷茶、被雨淋湿的账本]
- 交互动作：[如：角色说话时用火钳拨弄炭灰掩饰停顿，火星溅在鞋面上]

【分镜动作流】（步骤化的动作与台词骨架）
1. [动作 1：角色推门而入，视线落点与物理反馈]
2. [动作 2 + 台词 1：短句台词，穿插道具交互]
3. [动作 3 + 反馈：对方的生理反应与反制动作]
4. [动作 4 + 冲突升级/结果]

【伏笔与钩子】
- 伏笔操作：[埋设 / 推进 / 回收 编号及细节]
- 章末钩子（仅末尾场景卡填写）：[悬念钩子十三式编号及具体内容]
═══════════════════════════════════════
```

## 二、场景卡拆解完整示例

### 章纲
```
第3章：客栈密信
- 林远在同福客栈接触神秘线人老王
- 试探交锋，老王亮出线索但要求信物
- 章末：窗外黑衣人窥视，留下师门信物
```

### 拆解生成的场景卡范例

#### 场景卡 #1
```markdown
═══════════════════════════════════════
场景卡 #1
═══════════════════════════════════════
【基础信息】
- POV视角角色：林远
- 具体空间与光线/环境：青云城·同福客栈大堂·夜·仅大堂梁上悬着两盏昏暗油灯
- 在场出场人物：林远、老王、店小二（背景）

【冲突与信息差】
- POV核心即时目标：确认斜对角喝茶的老头是否就是接头人"老王"
- 核心物理阻碍/对抗：老王伪装成普通旅客，低头喝茶不露声色；林远需用暗号试探
- 信息差分布：
  - POV知晓：接头暗号是"天凉好个秋"
  - 对方知晓：自己掌握密信下落，但需确认林远佩剑路数
  - 双方均未知：客栈外已有暗哨封锁街道

【情绪走向与物理反馈载体】
- 情绪变化曲线：从 观察戒备 → 走向 试探确认
- 绑定的生理/动作载体：筷子在桌角磕齐、视线越过粗瓷碗沿、手腕肌肉微绷

【环境道具交互】
- 指定道具：油腻的木板凳、一碗凝了白油的凉面、空了的紫砂小茶壶
- 交互动作：林远端起粗瓷茶碗掩饰视线；老王手持空壶对着空杯倒了两次

【分镜动作流】
1. [林远拉开板凳坐下，抽筷磕齐，面已凉，端茶碗抿一口]
2. [视线越过碗沿锁定老头，老头紫砂壶已空却仍在倒茶]
3. [台词-短句] 林远："天凉了。"（碗底在桌上擦出一声轻响）
4. [反馈：老头倒茶的手停在半空，眼皮抬起，视线落在林远右手虎口的老茧上]

【伏笔与钩子】
- 伏笔操作：埋设 F-005（老头握壶的手指关节粗大，为军中截脉手法）
═══════════════════════════════════════
```

## 三、场景卡质量审查标准

拆解完成后，在生成正文前必须自检以下 6 项：
- [ ] 每张卡均指定了**具体的物理环境与光线**（无抽象空间）；
- [ ] 每张卡均绑定了**至少 1 件具体环境实物道具**并设计了交互动作；
- [ ] 情绪走向有**具体的生理/肢体动作载体**（无空洞形容词）；
- [ ] 动作分镜流清晰，骨架台词简短有力、带有潜台词；
- [ ] 信息差明确，无未卜先知的上帝视角；
- [ ] 最后一卡明确挂载了章末钩子。
