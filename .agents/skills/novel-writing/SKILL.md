# 小说全流程创作引擎

整合工程化长篇管理 + 动作分镜解耦生成 + 物理白描去机味质检的完整创作系统。

## 核心流程总览

```
设定与文风建库 → 卷纲规划 → 章纲拆解 → 场景卡组装(绑定物理交互) → 动作分镜生成 → 感官正文扩写 → 去AI味深度润色 → 状态归档 → 双轨逻辑审稿
```

每个阶段有明确输入输出，前一阶段的输出是后一阶段的输入。任何阶段可回溯修改。

---

## 阶段一：设定与文风建库

在开始创作前，将世界观、文风基准、角色、时间线、势力关系分文件存储，防止长篇连载时设定漂移与文风机化。

### 文件结构

```
novel-project/
├── 设定/
│   ├── 世界观.md             # 世界观：地理/历史/力量体系/社会结构
│   ├── 文风基准.md           # 文风基准库：句式节奏/五感标杆/Few-Shot样本（技能内参考件见 style-benchmark.md）
│   ├── 设定汇总目录.md       # 设定体系总目录：已有/待建文档登记与优先级
│   ├── 角色/
│   │   ├── [角色名].md        # 每个主要角色独立建档（含语言/行为锚点）
│   │   └── ...
│   ├── 全文总纲.md           # 时间线：大事件按时间排列
│   └── 势力关系图.md         # 势力与利益冲突图
├── 大纲/
│   ├── 第[N]卷大纲.md        # 每卷大纲
│   └── 第[N]卷章纲.md        # 每卷章纲
├── 正文/
│   ├── 第[编号]章-[章名].md  # 最终定稿正文
│   └── ...
└── 状态/
    ├── 角色状态追踪.md        # 角色实时状态表（见 memory-tracker）
    ├── 伏笔追踪表.md          # 伏笔追踪表
    └── 道具持有表.md          # 道具与装备持有表
```

### 角色身份证模板

每个角色文件必须包含以下结构（详见 [reference.md](reference.md) 的"角色身份证"章节）：

```markdown
# [角色名]

## 基础信息
- 年龄/性别/身形特征
- 身份/职业/阵营
- 核心动机（驱动角色一切行动的根本欲望，1句话）

## 气质与识别锚点（杜绝千人一面）
### 视觉锚点（3个标志性视觉特征）
1. [特征1：如"洗得发白的青布袍，袖口用麻绳扎紧"]
2. [特征2：如"右眉骨有一道寸许长的白疤"]
3. [特征3：如"看人时习惯微微低头看地面"]

### 语言锚点（说话方式与台词习惯）
- 句式习惯：[如：短句为主，极少使用连接词，从不说反问句]
- 禁用表达：[如：绝对不说成语，从不自称"在下"]
- 用词偏好与口头习惯：[如：粗俗/简洁/说话前习惯停顿半拍]

### 行为锚点（3个标志性动作）
1. [动作1：如"紧张时下意识摩挲短刀刀柄缠绳"]
2. [动作2：如"生气时反而变得极其安静、语速变慢"]
3. [动作3：如"说谎前会不自觉地先咽一口口水"]

## 人物弧光与成长路线
[角色从开始到结局的变化轨迹与战力变化]

## 行为禁区（绝对不可违背的底线）
- [如"绝不对妇孺拔刀；答应的事必须做到"]
```

## 阶段二：卷纲规划

为每卷创建宏观大纲与情绪曲线。

### 卷纲模板

```markdown
# 第[N]卷：[卷名]

## 卷级核心目标
[本卷要解决的核心利益争夺/达成的核心战略目标]

## 爽点节奏与情绪曲线（网文向）
| 章节区间 | 节奏定位 | 核心剧情事件 | 读者心理预期 |
|----------|----------|--------------|--------------|
| 1-3章    | 引入-钩子 | 遭遇外部冲突，设立即时悬念 | 期待破局 |
| 4-6章    | 压抑-蓄力 | 困境与阻碍升级，信息差收紧 | 代入紧迫感 |
| 7-9章    | 爆发-爽点 | 逆转/突破/打脸/资源获取 | 情绪释放 |
| 10-12章  | 余波-新钩 | 利益收束 + 抛出更高维度冲突 | 期待下一卷 |

## 关键转折点
1. [转折点1]：触发条件 → 连锁反应
2. [转折点2]：触发条件 → 连锁反应
```

## 阶段三：章纲拆解

将卷纲中的每章拆解为可执行的章纲。

### 章纲模板

```markdown
# 第[N]章：[章名]

## 本章基础信息
- POV角色：[视角角色]
- 目标字数：约[N]字
- 在卷中位置：[开篇/发展/高潮/收束]
- 本章主线进度：[推进的核心事实]

## 场景规划（2-3个场景）
1. 场景一：[出场人物 / 空间地点 / 核心对抗事件]
2. 场景二：[出场人物 / 空间地点 / 核心对抗事件]
3. 场景三：[出场人物 / 空间地点 / 核心对抗事件]

## 章末钩子
[类型：信息中断/危机降临/身份揭示/道具异动等，见 reference.md "悬念钩子十三式"]

## 核心卖点位（2026-09-28新增·防金手指断供）
[本书核心卖点/金手指（招牌动作）在本章是否出场：是（名义/形态）｜否（**必须写明主动理由**）]——与「每3章一个小爽点」同为逐章硬标注；长篇最常见的卖点死法是"中后期忘了用"，靠栏位不靠记忆。

## 本章应推进的伏笔
- 埋设：[伏笔编号及内容]
- 推进/回收：[伏笔编号及处理方式]
```

## 阶段五：正文两步解耦生成（核心突破）

**绝对禁止**在单次生成中同时处理“推演复杂剧情”与“雕琢文学细节”。大模型必须强制执行两步法：

### 步骤 1：生成动作分镜流（Action Script）
输出无任何形容词修饰的纯物理动线与骨架台词：
```markdown
- [林远推开虚掩的木门]
- [视线落点：桌角青花茶盏还在冒热气，椅面有轻微摩擦痕迹]
- [动作：反手合上门栓，右手拇指顶开刀鞘半寸]
- [台词-短句] 林远："出来。"
- [反馈：屏风后传来衣料摩挲声与轻微的铁器碰撞声]
```

### 步骤 2：感官正文扩写（Sensory Expansion）
严格对照 `设定/文风基准.md` 的文风基准与 `de-ai-humanizer.md` 的禁用清单，将动作分镜流扩写为正式正文：
- 落实白描与五感交互（温度、气味、触感、声音、光影）；
- 严格执行单句长度压制（冲突段 ≤10 字，普通叙事 ≤20 字）；
- 执行白描对白（省略冗余说话人标签，穿插动作交代说话者）。

## 阶段六：去AI味深度润色

正文扩写后必须经过深度扫描与物理化置换，详见 [de-ai-humanizer.md](de-ai-humanizer.md)。

### 核心禁令与扫描（命中即改）
- 🔴 **严禁套路微表情**：嘴角勾起/上扬、眼中闪过一丝、倒吸凉气、瞳孔收缩、深吸一口气、冷哼一声；
- 🔴 **严禁心理声明**：心中涌起、感到无比愤怒/绝望、内心充满了、前所未有的压力；
- 🔴 **严禁套路过渡与上帝旁白**：只见、殊不知、那一刻、不知不觉、刹那间、空气中弥漫着；
- 🔴 **严禁二分议论句式**：不是A而是B、不仅是A更是B、与其说A不如说B；
   - 🔴 **严禁解说员句式**：总结式判断（"这是……唯一的活路"）、解释性说明（"他来自的那个世界，把这叫物理"）、评价性语句（"他不是没天赋。他是没敢花。"）、全知信息（角色不可能知道的信息）、戏剧化揭示（旁白式悬念制造）、自我解释型收束（"不说，就不说了"类AI陷阱句式）；详见 de-ai-humanizer.md §4.5；
- 🔴 **严禁章末感悟八股**：他终于明白了一切、这一刻他懂得了、望着远方心中已有答案；
- 🔴 **严禁空洞宣传腔**：前所未有的力量、惊天动地、震撼了整个X界、恐怖如斯。

## 阶段八：双轨逻辑审稿

每章或每卷完成后进行独立质检，详见 [critic-qa.md](critic-qa.md)。

### 双轨审查维度
1. **轨道 A（设定与逻辑硬指标）**：战力一致性（无无端突变/伤势体现）、世界观闭环、信息差合规、伏笔健康度。
2. **轨道 B（文风与去机味硬指标）**：
   - 🔴 **严重（直接退回）**：命中 40+ 禁用套话/微表情/心理声明/章末八股；
   - 🟡 **警告（建议改写）**：战斗段长句堆叠、缺少环境实物落点、对白千人一面未通过名字遮盖测试。

## 七、批量写作与"防产幻"纪律（2026-09-27 增补·实证来源）

> 本节由《消失的灵气》卷1 实战复盘得出。**长篇连载最大的失败模式不是文笔差，是"写到后面忘了前面"**——即"产幻"（作者写着写着，自己都被自己前文带偏，产生与设定库矛盾的幻觉内容）。

### 7.1 批量写作铁律：**分批 + 强制回看**

**禁止一次性生成多章**（>5章）。单次输出上限与注意力衰减会共同导致：设定漂移、伏笔错位、人物性格漂移、时间线混乱。

标准工作流：

```
写 3-5 章 → 强制复盘（机械+内容）→ 修正硬伤 → 汇报 → 再写下一批
```

每批复盘**必须**执行以下三项，缺一不可：

#### ① 机械检查（用脚本，一次跑完）
```python
# 字数 + 半角标点 + 纪律词扫描
import re, glob
for f in sorted(glob.glob('正文/*.md')):
    s = open(f, encoding='utf-8').read()
    h = len(re.findall(r'[\u4e00-\u9fff]', s))
    n = len(re.findall(r'[^\u4e00-\u9fff\s]', s))
    half = len(re.findall(r'[一-鿿],[一-鿿]', s)) + s.count('?') + s.count('!')
    print(f'{f} {h+n}字 半角{half} {"OK" if half==0 else "⚠️"}')
```
配套 grep 扫描禁用套路（见阶段六清单）与报告味词（物理单位/参数化表述）。

#### ② 内容复查（必须人工/逐章读，不可跳过）
- **空间与距离自洽**：距离/步数/耗时三者必须能对上（**实战踩坑**：写了"据点往里二十里"又写"四十七步"，物理上不可能成立）
- **时间线自洽**：人物年龄、卡关年数、事件先后
- **设定库比对**：与角色卡/世界观/锚点清单逐条核，**正文新增设定必须回写锚点清单**
- **跨章衔接**：上一章末状态 = 下一章首状态（伤势/位置/时间/情绪）
- **状态连续性（2026-09-28新增）**：已耗尽/已掩埋/已赠出的物品不得"复活"（**实战踩坑**：盐在正文第2章整袋扬出，第12章又写"去了三斤回来半斤"）；旧识关系不得写成初会（**实战踩坑**：第3章已立"跛脚刘收过他的盐"，第17章又互报姓名）——写物品戏前查道具持有表，写人物戏前查角色状态表

#### ③ 锚点回写（防遗忘的关键）
**正文里每出现一个新设定碎片（物品、地点、台词、规则、口径），必须立即回写 `设定/已固化锚点清单.md`**，否则写到卷5时会想不起卷1埋过什么。**回写必须对账（2026-09-28新增）**：登记新锚点前先与道具持有表/角色状态表核对——两个文档登记互相矛盾的条目比不登记更危险（**实战踩坑**：锚点登记「老槐识破盐袋·与第1节拍口径一致」，与道具表「精盐已耗尽」直接打架，一周后才被发现改写）。发现矛盾时按「正文成稿优先」原则当场裁决，锚点清单加删除线+裁决日期。

### 7.2 设定冲突的自查方法（实战高频）

写作时容易"顺手编一个数字"，与设定库冲突。**每写完一章必须问自己四句**：

1. 这个数字/年限/距离，设定库里有没有既定值？→ 有则以设定库为准
2. 我写的这个数，和角色已有的经历**逻辑上说得通吗**？（实战踩坑：老槐设定是"三十年苦修到练气7层"，我写他"卡了三年"——那剩下27年怎么突破？逻辑崩了）
3. 这个设定**要不要进锚点清单**？→ 要，且要带"改写理由"
4. **这个人/物的状态还连续吗**？（2026-09-28新增）物品是不是已耗尽/已埋/已赠人，关系是不是已旧识/已交恶/已知情——写对话前先过两张状态表（实战踩坑：盐复生、旧识生人化、"十三年前"对不上24岁年龄账、老槐"刚来二十一"对不上27岁入界档案）

### 7.3 口径变更纪律

项目裁决变更（如字数区间、书名、人物设定）时，必须：
1. 找到**所有**引用该口径的文件（`grep -rn`）
2. 逐个改，并在权威源标注"作废/新裁决 + 日期"
3. 评估连带影响：口径变更可能让已成稿章节变成"超标/不合规"——**处理方式是标注为历史口径达成、不回溯返工**，除非内容确有硬伤
4. **不要只改权威源**——权威源改了、其他引用点没改，是最常见的"口径分裂"

### 7.3.1 字数口径纪律（2026-09-29 增补·实证反噬，推荐所有项目采用）

**默认口径：设下限，不设硬上限。**

- 每章 **不少于 ~2400 字**（Word口径：汉字+标点各计1字）为硬下限；**不设硬上限**，上限以上一律合规，不因"超标"返工
- 可给一个"目标带"（如 2800-3200）作**写作参考**，但它是**建议值，不是验收线**
- 🔴 **优先级铁律：当字数与内容完整性冲突时，内容完整性永远优先。**

**明令禁止的四类"卡字数"操作**（每一条都来自真实踩坑）：
1. 删掉场景必需的**承接段**，导致前章钩子在后章没有落点、上下两段对不上
2. 为压缩把一个**完整场景切成两半**，段落落到无引子的悬空位置
3. 删掉**铺垫对白**，让后文的推断/反转失去依据
4. 用心理独白、重复信息、机味议论句**注水凑数**（与"补写"方向相反，同样禁止）

**下限不是水线**：因内容需要自然跌破下限（快速过场章、纯动作章）可接受，但需在批次复盘说明理由；因内容需要自然超出上限（闭环章、多线汇流章）**不视为超标**。

**为什么必须废除硬上限**（实证）：《消失的灵气》第19章成稿时，初稿 4452 字，硬上限 3200。为压进区间做了 20+ 轮删减，代价是**制造了原稿不存在的结构损伤**——一处场景结尾被切到 `---` 分隔符另一侧，上下文直接断裂，花两轮才修复复原；另有多处承接段被削薄。**即：硬上限会把"为了不超标"异化为"为了达标而扭曲结构"，产出的代价高于收益。** 字数是结果，不是目标；先写对，再看字数。

**配套机检调整**：字数检查脚本应改为**只报警下限**，不报警上限：
```python
h=len(re.findall(r'[\u4e00-\u9fff]',s)); n=len(re.findall(r'[^\u4e00-\u9fff\s]',s))
print(f'{f} {h+n}字 {"⚠️低于下限" if h+n<2400 else "OK"}')  # 超过目标带不报警
```

> 项目级教训库见 `状态/写作经验教训库.md`（《消失的灵气》），每条实战踩坑带日期与实例。

### 7.3.2 生成失控检测（2026-09-29 增补·第20章实战失控后补）

> **症状**：一次生成中 AI 反复重放同一场景、人物名错乱、混入非中文、段落之间毫无衔接。**它不报错、不中断，字数甚至达标**——字数/半角/禁词机检全部通过，肉眼才看得出。**纯机检抓不到这类问题。**

**成因**：单次生成试图覆盖过多内容（本次一章跨4天、6个场景），超出单次输出稳定承载，AI 开始"卡带"重放。

**预防**：
1. **一章最多拆 3-4 个场景**，按时间跳跃明确切分
2. **每次 editor 写入控制在 3000 字以内**，超了就分次写
3. **禁止一次生成跨越"日"**（第1天写完就停，另起一次写第4天）

**检测脚本**（每场写完立即跑，别等全章）：
```python
from collections import Counter
paras=[x.strip() for x in body.split('\n\n') if x.strip()]
dup=[(v,k[:40]) for k,v in Counter(paras).items() if v>1]
if dup: print('⚠️重复段落:',dup)   # 刻意复沓可以有；整段无差别重复=失控
for pat in ['下楼','上楼','翻到最后一页','把担子']:
    c=len(re.findall(pat,body))
    if c>3: print(f'⚠️动作循环 {pat}×{c}')   # 同一动宾>3次且无叙事变化=卡带
segs=s.split('\n---\n')
tot=sum(len(y.strip()) for y in segs)
for i,x in enumerate(segs):
    if len(x.strip())>tot*0.25: print(f'⚠️第{i}段臃肿 {len(x)}字')
```

### 7.3.3 分场字数预算（2026-09-29 增补·第20章事后总结）

设下限不设上限之后，风险从"被字数绑架"转成"章节无限膨胀"（第20章5323字＝旧目标带1.7倍）。

**开工前先分配预算**：一章 4-6 场，**每场 ≤ 总预算/场数**；单场超总章长 30% 即判臃肿，回头看是否有两场可合并。

**"不设上限"指的是不必为凑数字删承接段，不是允许注水**——区别在于：删掉会破坏结构的是硬伤（不许删），重复同一动作/同一场景的是注水（该删）。

### 7.3.4 数量账纪律（2026-09-29 增补·跨章算术自洽）

> **这是"产幻"最隐蔽的一种**：数值不与设定库冲突（全是新编的数），机检全过（字数/半角/禁词），但**同一物件在第3章和第17章的量对不上**。**没有任何现有规则能抓住它。**

**典型症状**（用户提出）：
> 第2章：有1斤 → 第5章：消耗2两 → 第9章：还剩半斤

**核心区分（关键）**：
| 类型 | 查什么 | 由谁负责 |
|---|---|---|
| **设定值冲突** | 这个数与设定库既定值矛盾吗 | §7.2 第1条 |
| **数量账冲突**（本条） | 同一物件跨章的加减乘除**自身守恒**吗 | **本条，无人负责** |

#### 硬性纪律
1. **凡出现可累加的量，一律建"数量账"**：药材重量、银钱、丹药颗数、路程里数、存粮、消耗品余量、修炼次数。**首次出现时登记在 `状态/道具持有表.md`，格式必须含"当前余量 + 计量单位"**。
2. **单位必须统一换算后再运算**：本书斤/两双单位（1斤=16两）；文/钱/两/灵石三轨（详见 `设定/通用/术语与称谓规范.md` §5.1）。**心算结果一律回读一遍**。
3. **每次动用该物品后，余额必须能倒推回去**：`上次余量 − 本次消耗 = 本次余量`。三个数必须同时成立。
4. **跨章不回溯的账，本章自己也要对得上**：哪怕读者不记得前章，本章内"给出→消耗→剩余"三步必须闭合。
5. **新增量值类数字，同步回写道具表/经济表**（物价入 `社会生活与经济.md` §二，余量入 `道具持有表.md`）。

#### 机检辅助（抓不到纯心算错误，但能抓明显矛盾）
```python
import re
# 抽取本章所有"数量+单位"，人工核对加减
for m in re.finditer(r'([一二三四五六七八九十百千两半\d.]+)\s*(斤|两|文|块|颗|枚|里|日|年|次|人|个)', body):
    print(m.group(0))
# 检查是否出现同一物件的两个不同余量
```
> ⚠️ 脚本只能列出待核清单，**守恒必须人工心算复核**。本书"斤/两""文/两/块"是双轨多轨，最易出错。

#### 已发生的教训案例
- **货币换算**：第17章「三块八涨到四块半」曾被误算为「往上走了七文」（实际是近两成）→ 已修正，规则记入术语规范 §5.1
- **年龄账**：第11-17章批次「十三年前…他十二岁」（24岁应为十二年前）→ §7.4 模式4
- **重量账（同类未爆）**：第19章「四块半一两。六两二十七块」——心算 6×4.5=27 成立，但**全程无校验步骤**，属高风险写法

### 7.4 跨轮同步失效五模式与归档门禁（2026-09-28 增补·实证来源：《消失的灵气》第11-17章批次复盘）

该批次17章正文**机检全过**（字数/半角/禁词），仍漏网8处P0级冲突——全部败在"内容复查与状态归档被跳过"。提炼五种失效模式，写作前对照：

| # | 失效模式 | 实例（第11-17章批次） | 防范动作 |
|---|---------|---------------------|---------|
| 1 | 消耗品复活 | 盐整袋扬出+半把掩埋（第2章），后文再现"去了三斤回来半斤"（第12章）、又埋一次"剩下的一半"（第16章） | 写物品戏前查道具持有表 |
| 2 | 旧识生人化 | 第3章已立"跛脚刘收过他的盐/赵四娘登记簿有名"，第16-17章又写成初次互报姓名 | 写人物戏前查角色状态表关系栏 |
| 3 | 设定值vs正文值漂移 | 设定库"据点—镇180公里"vs正文"大路六十里、三时辰走全程" | 距离/旅程戏对账地理表；冲突按"正文成稿优先、反写设定、登记理由"裁决 |
| 4 | 年数年龄漂移 | "十三年前…他十二岁"（24岁年龄账应为十二年前）；老槐"刚来，二十一"（与27岁1995年入界档案冲突） | 凡涉年数的句子对前史年表+角色卡双查 |
| 5 | 新设定悬空未裁决 | 第15章新盖"第四户"无归属悬置（后裁决为万法宗前哨F-018——顺手把事故变成伏笔，但这是运气不是流程） | 批次结束前，全部新增具名设定登记归属（或显式标"待裁决"+截止节拍） |
| 6 | **数量账漂移**（2026-09-29新增） | 同一物件跨章的量算不拢：1斤→消耗2两→还剩半斤。**不与设定库冲突、机检全过，纯靠心算**，现有五模式全部漏网 | 见 §7.3.4。凡可累加的量登记数量账；每次动用后 `上次余量−本次消耗=本次余量` 三数须同时成立；斤/两、文/两/块双轨多轨必须先换算再算 |

**归档门禁（铁律）**：上一批次（3-5章）的状态四表（角色状态/道具持有/伏笔追踪/时间线）+锚点回写未完成，**不得开写新批次**。归档不是文书工作，是唯一的"产幻"拦截闸——本批次8处冲突里有6处可在此闸前拦下。
