## 一、阵法分类与品阶

### 1.1 六大分类

| 类别 | 功能定义 | 典型应用场景 | 代表阵法 |
|------|---------|------------|---------|
| **聚灵阵** | 汇聚天地灵气于特定区域，提升局部灵气浓度 | 宗门修炼场、洞府、灵田催熟 | 小聚灵阵、大衍聚灵阵 |
| **防护阵** | 形成灵气屏障抵御外力侵入 | 宗门山门、据点防御、随身护体 | 磐石守御阵、玄光壁障 |
| **幻杀阵** | 以幻象迷惑+灵气攻击组合的攻防一体阵法 | 秘境守卫、伏击、禁地封锁 | 迷踪幻阵、七煞困杀阵 |
| **推演阵** | 以灵气为媒介进行数理运算和天机推演 | 阵法设计验证、灵脉勘测、天象预测 | 天枢推演阵、九宫算阵 |
| **通讯阵** | 远距离传递灵气信号或信息 | 宗门内部联络、帝国军情传递、商队定位 | 传音阵、灵息感应阵 |
| **监测阵** | 持续感知并记录区域内的灵气变化 | 灵脉监控、异常入侵预警、环境评估 | 观澜监测阵、灵潮记录仪阵 |

### 1.2 阵法品阶

| 品阶 | 判定标准 | 布阵门槛 | 维持消耗 | 说明 |
|------|---------|---------|---------|------|
| **基础阵** | 单一功能、结构简单、阵眼不超过七个 | 练气期可独立布置 | 极低或无需持续供能 | 入门级，散修可用 |
| **中阶阵** | 复合功能、结构较复杂、阵眼七至二十个 | 筑基期阵法师 | 需定期补充灵石或接入灵脉 | 宗门日常使用主力 |
| **高阶阵** | 多功能集成、精密联动、阵眼数十至上百 | 金丹期阵法师主导 | 需接入灵脉或有专人维护 | 宗门核心设施 |
| **宗师阵** | 涉及天地法则层面的阵法，往往与地理/灵脉深度绑定 | 元婴期以上阵法师 | 以灵脉本身为能源 | 镇宗级、国家级工程 |
| **天道阵** | 传说级，以天地本身为阵体 | 化神级或特殊条件 | 自循环 | 归藏界现存不超过三座；初代祖师所留引灵阵眼属此类遗存（F-007，卷5回收） |

## 二、阵法师等级与养成路径

### 2.1 等级体系

| 等级 | 对应修为 | 能力范围 | 社会地位 |
|------|---------|---------|---------|
| 阵法学徒 | 练气期 | 识阵、抄阵、辅助布设基础阵 | 杂役级 |
| 初级阵法师 | 练气后期-筑基初期 | 独立布置基础阵、维修中阶阵 | 受尊重的技术人员 |
| 中级阵法师 | 筑基中后期 | 设计并布置中阶阵、参与高阶阵工程 | 各势力争抢 |
| 高级阵法师 | 金丹期 | 主导高阶阵设计与施工、改良现有阵法 | 宗门长老级待遇 |
| 阵法大师 | 元婴期 | 设计宗师阵、修复古阵、开创阵法理论新分支 | 各宗国宝级 |
| 阵法宗师 | 化神级或天赋极致 | 触及天道阵层面 | 传说级 |

### 2.2 天衍宗——最正统的阵法传承

- **核心地位**：天衍宗是归藏界阵法领域的绝对权威。三大帝国皇室阵法师均出自天衍宗培养体系
- **教学体系**：外门教基础阵法理论与实操；内门阵法堂教授高阶阵法设计与推演；核心弟子可习《天枢算经》
- **与大乾帝国的绑定**：大乾皇室御用阵法师由天衍宗定向培养并输送。这些阵法师同时掌握皇室约30%的核心机密（以"封存阵法"形式存于天衍宗禁地），这是天衍宗超然地位的底层支撑（世界观§5.2）
- **林晚的位置**：内门弟子，师从阵法堂长老青玄真人。天赋远超同辈但因功法瓶颈停滞三年

### 2.3 其他势力的阵法能力

| 势力 | 阵法特点 | 水平定位 |
|------|---------|---------|
| 万法宗 | 侧重功法配套阵法（聚灵、护法），理论水平不及天衍宗 | 中上 |
| 玄机阁 | 侧重法宝炼制中的微型阵法刻制，精密度极高但规模偏小 | 精度最高，规模有限 |
| 幽冥殿 | 侧重监测阵与感知阵（天听司阵法网），实战导向 | 监测领域顶尖 |
| 太虚门 | 保存最古老的阵法文献，理论研究深厚但实操传承不如天衍宗 | 理论最强，实操次之 |
| 三大帝国 | 依赖天衍宗输出人才，自有阵法团队水平中等 | 应用层 |
| 散修 | 基础阵为主，偶有民间传承的中阶阵 | 参差不齐 |

## 三、天衍宗阵法三百年传承脉络

> 对齐第1卷第2-3节拍台词（男频版20节拍·随药庐线前移）："天衍宗阵法传承三百年"。

### 3.1 传承纪年

| 时期 | 事件 | 备注 |
|------|------|------|
| 约三百年前 | 天衍宗初代阵法祖师在云屏镇以北的天衍山立派，观测天门遗迹（传说层），开创以算学入阵的独特传承 | "阵法传承三百年"即指此起点 |
| 两百五十年前 | 第二代掌门完善推演阵体系，《天枢算经》初稿成形 | 天衍宗从普通宗门跃升为五大宗门之一 |
| 一百八十年前 | 与大乾帝国确立御用阵法师供给关系 | 政治绑定的起点 |
| 一百年前 | 《听澜诀》末卷失传（具体原因宗门档案语焉不详） | 林晚瓶颈的历史根源 |
| 三十年前 | 青玄真人游学太虚门，接触天门传说古籍 | F-003信息链的关键节点 |
| 十年前 | 青玄真人收林晚为徒 | 新一代传承的开始 |

### 3.2 初代祖师传说层

- 传说初代祖师曾在天衍山巅观测到"天门残影"——一道转瞬即逝的灵气异象。他以此为契机创立了以"观天推演"为核心的阵法体系
- 这一传说在天衍宗内部被视为宗门起源神话，多数弟子不当真
- **接口预留**：初代祖师所留引灵阵眼（F-007）与此传说的关联在第5卷回收——传说不是纯粹的神话，而是对真实事件的模糊记忆。此处只记传说层内容，不剧透回收细节

### 3.3 "三百年都是对的"之争

- 林晚在第1卷第2-3节拍的台词"传承三百年不代表三百年都是对的"直指两个问题：一是《听澜诀》末卷失传暴露了传承本身的脆弱性；二是如果灵气环境在三百年间发生了变化，那么三百年前设计的功法和阵法是否仍然适用（**男频版20节拍·2026-09-02**：台词随林晚出场前移至药庐线）
- 这个质疑在当时被视为异端，但在第5卷灵气衰减被证实后成为先见之明
