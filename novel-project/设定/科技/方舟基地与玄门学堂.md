## 一、方舟基地功能分区

方舟基地位于华国西南某省喀斯特溶洞群深处，紧邻裂隙蓝星侧入口，是玄门工程蓝星侧指挥中枢与综合保障基地。地面伪装为废弃矿区+地质监测站，地下纵深七层，总面积约12万平方米。以下分区按工程代号命名，日常交流中人员以代号代称。

|---------|------|----------|---------|------|

### 渡津口（F区）穿行与洗消流程

| 步骤 | 内容 | 耗时 | 说明 |
|------|------|------|------|
| 1. 通行登记 | 身份核验+任务单确认+随身物品清单录入 | 5分钟 | 调度台值班员执行，双人复核 |
| 2. 穿戴检查 | 着装合规检查（无违禁品、伪装服饰完整性）、灵波通讯器/香漏等制式装备确认 | 3分钟 | 违反即驳回，不得申诉 |
| 3. 「盲渡」装载 | 佩戴防神识防透光眼罩，进入全封闭「盲箱货柜」 | 5分钟 | 严格执行绝密穿行规程（详见下方 1.3） |
| 4. 盲箱穿行 | 摆渡人勤务组推引货柜通过裂隙 | 数秒至数十秒 | 体感为短暂维度挤压不适；外界光线/方向完全屏蔽 |
| 5. 洗消走廊 | 物理清洁+衣物更换+体表灵气残留初步清除 | 15-20分钟 | 单向通道，不可逆行（返程必须） |
| 6. 灵息残留处理 | 进入灵息处理室，由科学组操作员使用调制设备将体表残留灵息调至安全阈值以下 | 20-40分钟 | 修士残留较强，处理时间长；凡人通常无需此步 |
| 7. 医学快检 | 基础体征+灵气暴露量快速检测 | 10分钟 | 异常者转入D区隔离观察 |
| 8. 出区放行 | 以上全部通过后签发「出区凭证」，方可进入基地其他区域 | 即时 | — |

> **注**：归藏界侧返回人员的洗消标准高于蓝星侧出发人员——返程携带的灵气残留是消化容量的主要消耗源之一，必须压到阈值以下才允许在基地内自由活动。

### 1.3 核心保密穿行机制：代号「盲渡」规程

为确保裂隙物理位置与进出路线的**绝对绝对安全**，玄门工程自1985年起强制推行「盲渡」规程。**全员（含第一层修士、第二层凡人、甚至顾承安与陈默）在离开与返回裂隙时，必须无条件执行全盲中转。**

```
┌──────────────────────────────────────────────────────────┐
│ 蓝星侧方舟F区：穿戴防神识眼罩 ──> 锁入全封闭「盲箱货柜」   │
└────────────────────────────┬─────────────────────────────┘
                             │ (专职摆渡人推引过界)
                             ▼
┌──────────────────────────────────────────────────────────┐
│ 归藏界侧地下溶洞迷宫 (玄洲中部荒山地下 48 处隐秘暗道)      │
└────────────────────────────┬─────────────────────────────┘
                             │ (计算机随机离散算法分配投放点)
        ┌────────────────────┼────────────────────┐
        ▼                    ▼                    ▼
   【A-07 枯井底】      【B-12 废庙地窖】     【C-04 巨木树洞】
   (交通员解锁摘罩)     (交通员解锁摘罩)      (交通员解锁摘罩)
   "独自走出，融入市井" "独自走出，融入市井"  "独自走出，融入市井"
```

#### ① 防搜魂与防足迹双重安全逻辑
1. **防止坐标外泄（防搜魂/防叛变终极防线）**：
   - 渗透人员的记忆中**完全不存在裂隙在归藏界的具体经纬度、山头特征与溶洞入口**；
   - 即使遭遇高阶修士搜魂或意外叛变（如段天涯），其脑海中也只有“在某枯井/废庙被摘下眼罩”的碎片记忆，从源头切断出卖裂隙坐标的可能。
2. **消除地面物理痕迹走廊（防闻香队/猎户追踪）**：
   - 杜绝几十年来数千人从单一山洞口进出踩出植被践踏带、汗液气味浓集线或道路走廊；
   - 每次穿行人员被随机分流至方圆数十公里内的不同出口，地面痕迹完全被荒山自然植被与市井人流稀释。

#### ② 「盲渡」四大执行标准（SOP）
1. **闭目封识**：穿戴内衬铅丝与隔音隔磁的特制「防透光/防神识窥探眼罩」，披挂灵息衰减斗篷，切断外界视觉与神识感知；
2. **盲箱密闭**：进入外观仿制归藏界普通重型运矿木箱、药材箱或兽皮木柜的「盲箱容器」。箱体内衬消音铅板，隔绝重力方向感与磁场定位；
3. **随机多点散布投送**：归藏界侧地下溶洞迷宫连接 **48 处不同隐秘出口**（枯井、废庙地窖、空心巨树洞、暗河溶洞口、采石场废坑等）。调度系统根据随机离散算法指定每次任务的投放点，由专职摆渡人推车送达；
4. **单线解封与逆向召回**：
   - 到达预定出口后，由该点专属单线交通员核验周边无敌情，解开盲箱锁并摘下眼罩，人员独自走出；
   - **返程同理**：返回人员严禁擅自寻找裂隙，必须在预定接应点（如老井、荒庙）被接应人员戴上眼罩、装入盲箱，通过地下暗道逆向运回裂隙。

## 二、玄门学堂

### 2.1 基本定位

玄门学堂是玄门工程第一层渗透人员的**系统化培训基地**，位于方舟基地C区（砺锋场）及配套教学区。招收16岁完成据点修炼期的候选人，学制四年（16-20岁），毕业后获授代号、正式启用。

### 2.2 课程体系

| 课程模块 | 课时比重 | 核心内容 | 考核方式 |
|---------|---------|---------|---------|
| 归藏界语言与方言 | 20% | 通用语精读、三大帝国主流方言（大乾官话/苍澜海商腔/北离军镇腔）、行话暗语、书面文体差异 | 笔试+情景对话实测（教官扮演本地人随机盘问，应答不自然即扣分） |
| 社会规则与礼仪 | 10% | 户籍制度、路引文书格式、宗门规矩、市井交易惯例、节庆习俗、禁忌事项 | 闭卷考试+模拟市集实操（设陷阱题：故意给出错误路引看能否识别） |
| 基础功法与灵根巩固 | 15% | 配发功法修炼（统一为基础引气诀，根据个人灵根属性微调）、灵气感知训练、经脉运行纠偏、练气期各层突破要点 | 修为实测+功法纯度评估（科学组仪器辅助检测灵气运行轨迹是否规范） |
| 情报技能 | 20% | 死信箱操作与网络构建、跟踪与反跟踪、密写术（化学/物理双轨）、信息传递编码、审讯与反审讯、线人发展与管理 | 实战对抗演练（红蓝对抗，互为猎物与猎人）；反审讯考核含压力环境下的信息保护测试 |
| 生存与伪装 | 15% | 野外生存（归藏界环境适配）、身份维持技巧、紧急撤离程序、伪装道具使用（气息马甲/一次性面孔等制式装备操作）、危机应变预案 | 72小时野外独立生存考核+身份维持连续测评（为期一个月的模拟渗透，全程被监控） |
| 心理建设与忠诚维护 | 10% | 身份撕裂应对、孤独耐受训练、双重家庭心理准备、同化风险自查、组织纪律与底线教育、归队心理调适 | 一对一心理评估（每季度）+小组互助讨论+毕业前综合心理鉴定 |
| 科技辅助素养 | 10% | 灵气检测仪操作与维护、灵波通讯器使用、数据记录规范、基础科学思维训练（不要求科研能力，要求能准确采集和上报数据） | 设备操作考核+数据采集实操（模拟任务中的数据质量评分） |

> **注**：课时比重为四年总体分配，不同学年侧重不同——第一年语言与社会规则占主导，第三年情报技能与生存占比上升，第四年以综合演练和心理建设收尾。

### 2.3 淘汰机制

| 项目 | 规则 |
|------|------|
| 淘汰率 | 四年累计约25%-30%（含主动退出与被动淘汰） |
| 淘汰判定节点 | 每学年末综合评定；任一模块连续两次考核不合格触发预警；心理问题经干预无效者随时可退 |
| 淘汰者去向 | 分两类处理，不搞洗脑、不搞记忆消除——组织依靠保密协议与岗位安置管理风险 |
| - 转岗安置 | 多数淘汰者转入蓝星侧后勤组、情报组分析岗、科学组辅助岗等不需要穿越裂隙的岗位；保留工程编制，签署终身保密协议 |
| - 退出安置 | 极少数不适合继续留在工程体系内的人员，安排至国家关联单位（地质勘探、科研院所等对口单位）就业，签署终身保密协议+定期回访制度；其此前接受的培训内容以「特殊人才选拔培训」名义归档 |
| 保密约束 | 所有淘汰者均受《特别保密条例》约束，泄露工程信息的法律后果明确告知；实际执行中靠岗位安置的归属感维系而非恐吓——「离开的人也是自己人」是学堂不成文的共识 |

## 三、家属安置与轮换制执行机构

### 3.1 家属安置体系

| 项目 | 内容 |
|------|------|
| 安置社区 | 方舟基地G区（栖云里）为核心安置区；另在基地周边省份设有3处外围安置点（以国企职工小区形态掩护），供不便入住基地的家属使用 |
| 掩护职业 | 渗透人员在蓝星的公开身份统一挂靠「某地质勘探公司」及其关联单位；家属对外说法为「长期驻外技术人员家属」；配偶可安排在关联单位从事行政/后勤类岗位 |
| 子女教育 | 基地内设临时看护点与小学辅导站；中学及以上就读地方学校，学费由工程专项经费补贴；子女不参与筛选体系（除非自愿且通过初筛） |
| 探亲安排 | 轮换回国期间可在G区与家人团聚；非轮换期原则上不允许探视，特殊情况（家属重病等）经审批后可安排视频通话（单向加密链路） |
| 经济保障 | 渗透人员薪资按军中特种岗位标准发放，额外有「跨界津贴」；家属享受住房、医疗、教育三项全额保障 |

### 3.2 轮换述职流程

轮换制依据世界观§4.3既定口径，此处落地为具体机构与流程：

| 步骤 | 执行机构 | 内容 | 时长 |
|------|---------|------|------|
