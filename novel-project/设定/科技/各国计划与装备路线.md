# 各国计划与装备路线

> **职责声明**：本文档是华国之外三国（联邦/北国/西欧）渗透计划的**单一载体**（设定目录 D3）。
> **权威层级**：服从 `世界观.md` §6.3、`势力关系图.md` 天门协议框架及各国计划名称等既定口径；本文档仅做体制细节、装备路线与辨识特征的落地补全。
> **引用规则**：正文涉及他国人员行事风格、装备特征、违规案例时，以本文档为准；若与世界观/势力关系图冲突，以上位文档为准并提修正记录。

## 一、联邦「新边疆」计划

### 1.1 体制特点

| 项目 | 内容 |
|------|------|
| 主导机构 | 联邦情报局（对外情报）+ 国防部（军事支援）联合运作 |
| 驱动逻辑 | 资本+军事双驱动：国会拨款受军工复合体游说影响，项目预算与「可量化回报」（灵物样本数、技术专利转化）挂钩；国防部视归藏界为战略资源储备区 |
| 决策风格 | 多头博弈：情报局要情报、国防部要资源、国会要政绩、承包商要合同——四方拉扯导致行动指令频繁变动，一线人员自主权大但后方支持不稳定 |
| 对华态度 | 将华国50年先发优势视为「不公平垄断」；谈判桌上要求「信息共享」，实际操作中试图绕过华国背书体系自行建立身份网络 |

### 1.2 人员构成与行事风格

| 维度 | 特征 |
|------|------|
| 选拔来源 | 情报局特工+军方特种部队退役人员为主，少量学术顾问随行；不要求从小培养，多为成年后短期培训（3-5年速成） |
| 入界风格 | **高调务实**：习惯用装备弥补经验不足，倾向于「技术解决问题」而非「融入环境解决问题」；对归藏界的态度类似「新边疆开拓者」——把归藏界当作待开发的资源场，缺乏对本土文明的敬畏 |
| 身份构建 | 依赖华国背书服务（初期配额条款约束）；自行构建的身份往往经不起深查——语言口音生硬、社会关系单薄、师承记录粗糙 |
| 团队协作 | 个人英雄主义倾向明显，小队内部竞争多于协作；指挥官难以统一调度 |
| 代表人物 | 代号「鹰」：精英特工出身，自信果断，咀嚼口香糖的习惯在归藏界格格不入但拒绝改掉——这种「不愿完全融入」本身就是新边疆计划的缩影（详见 `角色/代号鹰.md`） |

### 1.3 核心弱点（情报战利用点）

- 语言伪装薄弱：速成培训无法消除口音和文化习惯差异，资深渗透人员一听便知
- 装备依赖症：一旦科技造物失灵或被收缴，应变能力骤降
- 后方不稳：多头决策导致补给和指令经常延迟或自相矛盾
- 低估本土势力：习惯性地将归藏界人视为「NPC」而非对手，容易因傲慢犯错

## 二、北国「永冬」计划

### 2.1 体制特点

| 项目 | 内容 |
|------|------|
| 主导机构 | 北国军事情报局（GRU系统）独立主导，无文官制衡 |
| 驱动逻辑 | 纯军事驱动：将归藏界视为「潜在战场」和「战略纵深」，目标是评估修士战力能否被武器化或对抗化 |
| 决策风格 | 垂直命令链，执行力强但灵活性差；一线人员权限极小，所有重大决策需逐级上报 |
| 对华态度 | 表面合作、暗中提防；对华国50年经验有实用主义尊重，但不信任华国会真正共享核心情报 |

### 2.2 人员构成与行事风格

| 维度 | 特征 |
|------|------|
| 选拔来源 | 军事情报局现役军官+特种作战人员；全部有实战经验，无学术人员 |
| 入界风格 | **粗暴直接**：习惯用力量和威慑解决问题；对归藏界的礼仪和社会规则缺乏耐心，倾向于「先接触再调整」而非「先观察再行动」 |
| 身份构建 | 偏好武师/镖师/佣兵等武力型身份——这类身份不需要精细的社会关系网，但也限制了情报获取的深度 |
| 团队协作 | 纪律严明但缺乏创造性；遇到预案外情况容易僵化 |
| 核心风险 | **连累所有人**：粗暴行事引发的本地冲突可能触发幽冥殿追查，波及所有蓝星渗透人员——这是势力关系图中「北国·升级」威胁的实质 |
| 代表人物 | 代号「熊」：第3卷起出场，粗暴行事导致北离帝国军方介入（总纲·卷3概览已定） |

### 2.3 违规行为模式

北国人员的违规不是偶发失误，而是体制性倾向：

| 违规类型 | 表现 | 后果 |
|---------|------|------|
| 强行接触本土势力 | 未经充分准备即主动接触中小宗门/地方武装，试图以「交易」换取资源或情报 | 引发怀疑、暴露非本源气息、触发巡天司关注 |
| 携带违禁品 | 习惯性携带蓝星武器/通讯设备入界，认为「不带装备等于裸奔」 | 违反天门协议第4条；留下可被他国和华国追踪的物证 |
| 无视伪装纪律 | 在非紧急情况下使用蓝星物品/语言/行为习惯 | 增加被本地人察觉异常的概率 |
| 过度使用武力 | 面对威胁时优先选择暴力回应而非规避/化解 | 制造事件、引起幽冥殿注意、连累其他蓝星人员 |

## 三、西欧「赫尔墨斯」计划

### 3.1 体制特点

| 项目 | 内容 |
|------|------|
| 主导机构 | 西欧联合研究院（多国学术联合体）主导，各国情报机构提供后勤与安全支持但不干预研究方向 |
| 驱动逻辑 | 学术驱动：核心目标是理解灵气的科学本质、修炼的生理机制、两界物理模型；资源获取是次要目标 |
| 决策风格 | 委员会制，决策缓慢但共识度高；研究人员有较大自主权，可根据发现调整研究计划 |
| 对华态度 | 对苏薇的科学组抱有真诚的学术交流意愿；尊重华国50年积累的数据优势，愿意以自身学术资源交换访问权限 |

### 3.2 人员构成与行事风格

| 维度 | 特征 |
|------|------|
| 选拔来源 | 物理学家、生物学家、语言学家、文化人类学者为主；少数安保人员随行但无权干预研究决策 |
| 入界风格 | **谨慎好奇**：倾向于长期观察和记录，避免主动干预；对归藏界文明有学术层面的尊重，愿意花时间学习语言和文化 |
| 身份构建 | 偏好学者/药师/工匠学徒等需要「问问题」的身份——这类身份天然允许好奇心，但也容易被识破「问的问题太系统了」 |
| 团队协作 | 合作性强、内部沟通顺畅；但与外界（尤其是军方和情报机构）存在信息壁垒 |
| 与华国接口 | 苏薇的科学组是天然对接方：双方共享灵气检测方法论、丹药成分分析数据、功法生理学研究成果；学术互信高于政治互信 |

### 3.3 核心弱点（情报战利用点）

- 安全意识薄弱：研究人员不习惯情报战的思维，容易在交流中无意泄露敏感信息
- 行动力不足：遇到危险时缺乏自保能力，依赖安保人员
- 过度透明：学术习惯导致他们对「谁在问什么问题」不够警觉，容易被第三方套取信息
- 进度缓慢：委员会决策+学术严谨=行动迟缓，在冷战博弈中抢不过联邦和北国

## 四、各国技术路线与装备特点对比表

| 维度 | 华国（玄门工程） | 联邦（新边疆） | 北国（永冬） | 西欧（赫尔墨斯） |
|------|----------------|--------------|------------|----------------|
| **总体路线** | 「嵌入本土」：50年积累，追求与归藏界社会无缝融合 | 「科技硬壳」：用装备弥补经验差距，快速形成战斗力 | 「军事突击」：以武力为底牌，快速接触、快速获取 | 「学术探针」：以研究为导向，重记录轻干预 |
| **通讯** | 灵波通讯器（三代迭代）+山神龛中继+死信箱网络；信号模拟天然灵气脉动，极低可探测性 | 蓝星微型卫星中继+加密无线电；功率较高，易被天听司阵法网捕捉为异常信号源 | 军用加密短波电台+人工信使；可靠性高但频次受限 | 低频声学记录+手写笔记为主；几乎不主动发射信号 |
| **伪装** | 气息马甲+一次性面孔+净香丸+检测仪三壳装；四代迭代，仿生/嵌入/限量三原则 | 基础服饰伪装+化妆术；无灵气层面的伪装手段，残留灵息不做处理 | 武师/佣兵身份为主，不做精细社会伪装；部分人员甚至保留军人体态 | 学者/学徒身份，服饰到位但行为模式偏「外来研究者」；灵气伪装不在能力范围内 |
| **记录** | 灵气检测仪数据采集+手写日志+存储晶片（铁麻雀传递）；数据标准化程度最高 | 微型摄像设备+电子记录仪；信息量大但足迹极高 | 军用侦察记录设备+手绘地图；侧重地形与兵力部署 | 田野笔记+标本采集+声学录音；侧重文化与自然现象 |
| **自卫** | 严禁携带现代武器（红线）；依靠修为+归藏界本土兵器+特工格斗术 | 违规携带折叠刀等小型武器（F-008案例）；私下研发「伪装成本土兵器的蓝星武器」 | 系统性违规携带武器；尝试将蓝星爆破物伪装成「雷符」 | 几乎不自卫；依赖随队安保人员（安保人员也受协议约束） |
| **装备辨识度** | 低——刻意抹除蓝星痕迹，器物外观全面本土化 | 中高——装备精致度超本土水平，金属加工精度暴露工业背景 | 高——军用痕迹明显，即使改装也留有制式化特征 | 中——记录工具和采样容器形制特殊，懂行的人能认出「这不是本地的东西」 |

> **情报战应用**：渗透人员在归藏界偶遇来路不明的「同行」时，可从对方装备的细节判断其国籍——这是第4-5卷冷战戏的重要辨识素材。例如：看到一个人用的匕首刃口过于均匀光滑，大概率联邦产；看到一个人的靴底纹路是模具压制而非手工缝制，大概率北国产。

## 五、他国造物辨识特征

供卷4-5冷战戏使用，每条均为可直接写入正文的具体辨识点：

### 联邦造物

| # | 辨识特征 | 说明 |
|---|---------|------|
| 1 | 金属件表面处理过于均匀 | 联邦装备的金属部件经过工业级抛光/镀层，表面光洁度远超归藏界手工锻造水平；即使故意做旧，磨损模式也是均匀的——手工锻打的磨损是不规则的 |
| 2 | 织物纤维排列规整 | 联邦使用的布料为机器纺织，经纬线间距高度一致；归藏界手工织布的间距有自然波动。内行人摸一下就能分辨 |
| 3 | 英语缩写字母残留 | 联邦人员在紧急情况下会在笔记/标记中不自觉使用拉丁字母缩写（如「N」「W」「ETA」）；即使事后涂改，笔迹压痕仍可辨认 |

### 北国造物

| # | 辨识特征 | 说明 |
|---|---------|------|
| 1 | 制式化改装痕迹 | 北国装备的改装方式带有明显的军工流水线特征：焊点整齐、螺栓规格统一、涂装为标准色号——与归藏界匠人的个性化手作完全不同 |
| 2 | 爆破物气味残留 | 北国尝试将化学炸药伪装成「雷符」，但炸药的硝基化合物气味与灵火燃烧的气味谱截然不同；嗅觉灵敏者可在近距离辨别 |
| 3 |  Cyrillic字母刻印 | 部分装备内部的序列号/生产批号使用西里尔字母，即使外壳做了本土化处理，拆解后可见 |

### 西欧造物

| # | 辨识特征 | 说明 |
|---|---------|------|
| 1 | 采样容器的密封工艺 | 西欧研究者使用的标本瓶/矿石盒采用橡胶垫圈+螺旋盖密封，这种工艺归藏界不存在；且玻璃透明度远超本土水平 |
| 2 | 测量工具的刻度精度 | 西欧携带的量具（尺、秤、温度计仿制品）刻度间距极其均匀，最小分度值小于归藏界任何量具；使用者测量的习惯性动作（读数时凑近、记录时写小数点）也是辨识线索 |
| 3 | 多语种笔记混用 | 西欧团队由多国学者组成，笔记中可能出现英/法/德等多种语言的混用；即使刻意只用通用语书写，术语翻译的不一致也会暴露 |
