# 蓝星造物与装备名录（科技修仙库）

> 本文件是全书科技造物的**单一载体**（设定目录 D1），承接世界观 §4.5「科技辅助修仙」「足迹管理」。
> 定位：科技是工具箱不是修仙本身——**修行靠功法，科技只做器物与辅助**。所有造物必须过三关：
> ①原理一句话说得通（符合灵气规则）；②足迹可管理（仿生/嵌入/限量三原则，消耗「消化容量」配额）；③**有剧情接口**（哪卷哪节拍用它——没有接口的造物不立项）。
> 状态标记：🟢 已在卷纲/章纲出现 ｜ 🔵 库存（已立项待投放）｜ 🔴 红线（禁止项）
> 另设**制式装备**一类（见第五节）：行动背景列装、随场景自然带出，不做新奇亮相，不占用每卷造物名额。

## 六、红线与反侦军备竞赛

**技术扩散红线**（科学组内部明令，剧情素材）：
1. 功法严禁印刷/电子化扩散——万法宗垄断的根基不能由华国亲手拆（也是消化容量自保）
2. 造物部署一律限量审批，与人员编制共用配额池
3. 赝品灵石禁入市场；一次性面具弃置必须回收
4. 电子设备原则上不入归藏界（足迹过大），机械式/仿生式优先

**幽冥殿的反制进化线**（猫鼠升级——科技修仙不是单方面碾压）：
- 卷2：天听司对「规律性非本源信号」的并案规程（二级警戒，已🟢）
- 卷4-5：「闻香队」建制——资深感知修士带队，专盯「味道太干净」「体质异常得太稳定」的人——气息马甲的有效性开始衰减，逼出第三代伪装思路
- 卷6：管委会时代反成笑话——当年藏了五十年的信号，如今是「衡津口岸」的通关申报项

| 原理一句话 | 灵石晶格能量的武器化失控释放——把「渡气瓶」匀速释放的原理反过来，让晶格储能在一瞬间崩解倾泻 |
| 威力 | 约当一名元婴修士的全力一击；对化神而言单枚可轻易抹除 |
| 威慑逻辑 | 饱和威慑：蓝星造得很多，化神拦不完所有——「你挡得住一枚，挡不住一百枚」，由此换来平等对话的席位 |
| 剧情接口 | 卷5卷末「灵能核弹」立项获批；卷6在归藏界某处远离裂隙之地试射对峙——名场面，震慑归藏界高层，逼出谈判桌 |
| 红线 | 试射选址远离裂隙（避免引爆壁障伤口）；止步试射、绝不用于生灵——蓝星守住这条线，才有资格谈「秩序」 |
| 代价 | 试射即击穿归藏界「禁武」心理底线，是谈判中蓝星必须付出的信任成本；故军控谈判成为管委会首批议题 |
| 主题注 | 科技仍不是修仙本身——它造不出灵气，只是把已有灵气推向失控的极端；威慑换来的是谈判资格，不是胜利 |
