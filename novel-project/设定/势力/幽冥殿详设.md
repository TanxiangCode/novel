### 巡天司·城镇巡查使派驻制

- 三大帝国主要城镇各派驻2-4名巡查使，任期三年一轮换
- 巡查使为练气后期至筑基初期的低阶修士，身份公开（着幽冥殿黑色制式短袍+左臂绣银纹司徽）
- 日常职能：巡视坊市、登记外来散修、受理民间举报、配合地方官府处理修士纠纷
- **关键漏洞**：巡查使级别低、俸禄薄、远离总部监管，极易被本地势力贿赂拉拢。陆衡第1卷正是通过贿赂云屏镇附近的巡天司外围巡查使，将「可疑散修陈默」的信息以非正式渠道递入幽冥殿系统
- 巡查使之上设「巡区总管」（筑基后期），每帝国2-3人，负责汇总辖区内巡查使报告并上报司部

### 断狱司·审判与关押

- 审判程序：提审→证物核验→当堂对质→司主裁决（重大案件需殿主批复）
- 关押设施：幽都山中狱分三层——外层（练气级违规者）、中层（筑基级）、深层（金丹级以上或特殊犯人）
- 于文海（代号青壁）被关押于中层，卷3审讯在此进行
- 断狱司不设刑讯——审讯以灵气封禁+心理施压为主。但灭影司移交的嫌疑人往往已经「预处理」过

### 灭影司·编制与行动模式

- 小队制：每队3-5人，队长筑基后期至金丹初期
- 行动原则：不留痕迹、不留活口（官方任务）、不留记录（私单任务）
- 灭影司修士着全黑无标识装束，行动时以面具遮面
- **秦无涯定位**：灭影司执事修士，金丹初期，面无表情，冷厉高效。卷3第13节拍被任命主持「异常修士」清查——这是他从暗杀执行者转为追查主导者的转折点

## 三、天听司运作细节（卷1-3追查戏骨架）

### 感知阵法网架构

天听司的核心资产是一套遍布归藏界主要区域的灵气感知阵法网络。该网络最初为探测域外天魔入侵而建，后扩展为监察修士异常的通用系统。

### 值班与初筛流程

```
感知阵法全天候自动运行
    ↓
值守弟子监控阵法输出（每班4人，三班轮换）
    ↓
出现「非本源气息」信号 → 自动标记为「待初筛」
    ↓
初筛判定（值守弟子+自动化阵法辅助）：
  ├─ 带侵蚀性 → 立即升级为「天魔疑似」→ 通知守壁司+灭影司
  ├─ 非本源但不带侵蚀 → 归为「体质异常/低优先级存疑」→ 存档
  └─ 信号过弱/单次 → 归为「噪声」→ 丢弃
    ↓
「体质异常」存档定期并案分析（每月一次例行，突发事件触发临时并案）
```

### 二次鉴定程序

- **触发条件**：①同一区域短期内多次出现「体质异常」信号（规律性）；②收到具体举报并与存档信号吻合；③上级指令
- **执行人**：资深执法者（筑基后期以上）亲自前往现场核验，不可远程代行
- **核验手段**：近距离灵气感知+面谈观察+行踪追溯+必要时强制灵息采样
- **判定结果**：
  - 确认无害 → 解除标记，归档备查
  - 存疑加深 → 升格为「监视对象」，通知巡天司跟进
  - 确认异常 → 移交断狱司或灭影司处置

### 对蓝星渗透人员的实际效果

- 蓝星人员残留灵息触发初筛后被归为「体质异常」——不带侵蚀性，优先级低
- 单人单次不构成威胁；但当同一区域多人多次触发（如据点撤离时通联干扰全功率开启），并案后呈现「规律性非本源信号」→ 升格为区域异常（二级警戒）
- **林晚的独特价值**：普通感知者会忽略此类微弱信号或归为体质异常，只有林晚极高的敏感度才能捕捉到「异质但不邪性」的细微差别

## 四、收录 P-14：灭影司「隐秘业务」专节

### 私单业务运作机制

| 环节 | 描述 |
|------|------|
| 接口人 | 灭影司外围联络人（非正式编制，通常为退休灭影司修士或与灭影司有旧的散修），在各帝国大城市设有固定联络点 |
| 委托方式 | 委托人不直接联系灭影司，而是通过接口人传递需求。接口人评估可行性后向灭影司内部转达 |
| 定价行情 | 基础价：练气级目标50枚中品灵石起；筑基级200枚起；金丹级面议。加急翻倍。灭影司抽成六成，接口人一成，执行人三成 |
| 记录方式 | 无官方记录。接口人以暗语记账，灭影司内部仅以代号标注。事后销毁 |
| 风险控制 | 若私单暴露，灭影司否认一切，接口人被弃卒保车。委托人同样被抛弃 |

### 为何比正规程序快且漏洞多

- **正规程序**：举报→巡天司受理→初查→上报→审批→执行。全流程留痕，层层审核，耗时数月至数年
- **私单渠道**：委托→接口人转达→灭影司接单→直接执行。无审批、无记录、无复核，数日内可启动
- **漏洞**：无审批意味着无监督；无记录意味着无法追溯；接口人可能同时为多方服务，信息交叉泄露风险极高

### 陆衡举报案作为活案例

- 陆衡通过家族旧识找到巡天司外围巡查使（非灭影司接口人，但属于同一灰色生态），花钱买通其将「云屏镇可疑散修」的信息以私人渠道递入幽冥殿
- 这不是灭影司私单，而是巡天司基层腐败——但它利用了同一套「非正式渠道比正式渠道快」的逻辑
- 这条信息最终被天听司并案时引用，成为二级警戒升级的佐证之一
- **叙事功能**：展示幽冥殿并非铁板一块，基层灰色操作既是渗透人员的漏洞也是陷阱

## 五、闻香队建制专节（卷4-5反制线）

### 编制来源

- 闻香队不是独立编制，而是天听司下属的特别行动小组
- 由谛音真人亲自挑选3-5名资深感知修士组成，另配2-3名巡天司借调人员负责外围跟踪
- 组建时间：三级警戒后，天听司意识到常规感知阵法网对「非本源但不带侵蚀」信号的识别效率不足，遂组建专人团队进行人工筛查

### 筛查手法

| 手法 | 描述 | 针对目标 |
|------|------|---------|
| 「味道太干净」检测 | 正常修士长期生活在灵气环境中，体味会带有所在地灵脉的气息烙印。若一个人体味过于均匀、缺乏地域特征，说明他可能近期才进入该区域或使用了伪装手段 | 气息马甲使用者 |
| 「体质异常得太稳定」检测 | 真正的体质异常者（先天特异、伤病后遗症等）其异常信号会随身体状态波动。若异常信号过于稳定不变，说明可能是人为制造的恒定信号 | 净香丸服用者 |
| 行为模式比对 | 对照本地散修的典型行为模式（采买习惯、社交频率、移动路线），筛选出「行为模板过于标准化」的个体 | 经过系统训练的渗透人员 |
| 交叉验证 | 将上述三类嫌疑人与天听司存档的「体质异常」信号进行时空交叉，寻找重合点 | 多重伪装叠加者 |

### 与气息马甲/净香丸的猫鼠关系

- 气息马甲（卷2投放）：第一代伪装思路，模拟本地灵脉气息谱覆盖自身残留。闻香队的「味道太干净」检测正是对此的反制
- 净香丸（卷5投放）：第二代伪装思路，口服缓释调制体味谱，从「穿」变成「吃」。但剂量误差会导致体味紊乱，闻香队老手凭经验能嗅出「腌入味儿的不自然感」
- **造物名录第六节联动**：详细技术参数见 `科技/蓝星造物与装备名录.md` 第六节「幽冥殿反制进化线」，此处不重复

## 七、幽冥契约条款清单

### 权限边界

| 条款 | 内容 | 实操解读 |
|------|------|---------|
| 第一条 | 幽冥殿不主动介入宗门内部事务 | 宗门弟子违纪、功法传承争议、长老更替等，除非涉及跨宗门犯罪或域外天魔，否则幽冥殿不过问 |
| 第二条 | 仅在「异常」被举报或感知到后方可介入 | 「举报」包括正式举报和非正式渠道信息；「感知」指天听司阵法网捕获的信号。二者至少满足其一才可启动调查 |
| 第三条 | 跨帝国执法须通报所在帝国官府 | 形式上的尊重，实际操作中多为事后通报。帝国官府无权否决幽冥殿行动，但可要求旁听审讯 |
| 第四条 | 审判结果可向殿主申诉 | 断狱司裁决非终审，殿主有最终裁量权。但殿主极少推翻裁决 |
| 第五条 | 灭影司行动须有司主以上授权 | 官方任务严格执行；私单业务的「授权」走非正式渠道，不在契约文本内 |
| 第六条 | 守壁司辖区为幽冥殿直辖，不受帝国管辖 | 幽都山及周边百里为幽冥殿独立辖地，北离帝国朝廷无权过问 |

### 契约的历史演变

- 初版契约签订于幽冥殿成立之初（约八百年前），彼时五大宗门联合授权，三大帝国背书
- 此后经历三次修订，每次都是幽冥殿权限扩大——域外天魔威胁加剧时，各方愿意让渡更多权力换取安全
- 当前版本（第四次修订，约两百年前）是权限最大的版本，也是各方不满最多的版本
