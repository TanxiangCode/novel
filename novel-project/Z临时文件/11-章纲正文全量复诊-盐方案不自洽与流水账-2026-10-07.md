## 一、问题一：一袋盐的方案不自洽（本轮核心）

### 1.1 同一袋盐，四张互相打架的脸

| 场景/文档 | 盐的身份 | 潜台词：盐在归藏界「多常见」 |
|---|---|---|
| 第1章 L103-115 | 买路钱（货币） | **常见**：陈默随手抛出半斤，护卫只评一句「行商带土盐，带精盐的是常走黑市的」——黑市货，人人认得 |
| 第1章 L113 / 第4章 L159-163 | 借口（身份掩护） | **常见**：「边镇人走远路都带这个。驱虫，防瘴」——连外门采药弟子都能一眼认出「这袋子装过盐」 |
| 第2章 L191-195 / 第3章 L43 | 物证（异界铁证） | **绝无仅有**：「眼前这个白，在这个世界，不存在」「归藏界没有这种盐。这白，就是『外头来的』四个字」 |
| F-017 / 万法宗详设 / 两界物理 §5.3 | 物证链（追凶原点） | **绝无仅有**：「归藏界不存在的白色晶屑」，万法宗要「花几年找一个不存在的西域盐商」 |

**这四张脸对同一个问题给出两个相反的答案**：盐到底是「边镇人常带、黑市流通的硬通货」，还是「归藏界不存在的天外来物」？

- 若它是**常见流通货**（第1/4章口径）→ 第2/3章「这个世界不存在」「外头来的」就是**假警报**——万法宗在崖顶捡到白盐，只会追一个走私网络，不会当成天外来物，F-017「两案并桌」的分量塌掉。
- 若它是**绝无仅有之物**（第2/3章 + F-017口径）→ 第1章随手抛半斤当买路钱、第4章挂着空盐袋被叶青鸾一眼认出，就是**自杀**——他等于把「外星护照」掏给敌人看。

**行为两端也对不上**：第3章里他为一个「这个世界不存在」的白色物证紧张到——把盐袋里外搓洗三遍、把半把余盐拌浮土埋了、给自己立「掺色/稀释/限量/分层」四条规矩；可第1章他刚随手把半斤同款盐当买路钱扔出去、还任它被靴子踩烂留在崖上（反而多留了一处物证）。一个「赢完自己擦屁股」的特工，和一个「把要命的东西随手抛」的行商，是两个人。

### 1.2 这个矛盾是哪来的

09 方案B（盐当买路钱，弃「一百二十两」）被采纳并落地。它的动机是好的——想借「同一袋盐既是买命筹码、又是夺命武器」做反讽。**但反讽的两半对「盐的常见度」要求相反**：当筹码，得让护卫认得它的价值（常见）；当武器/物证，得让它的白绝无仅有（罕见）。09 写「盐从保命筹码翻转为夺命杀招」时，漏了这层互斥。

**结论：这不是措辞能修的，是「盐该不该流通」这个设定裁决没做。**

### 1.3 章纲层还有一个远期雷（已埋、未爆）

- 节拍1（第1-3章）确立：**白盐 = 归藏界熬不出 = 异界铁证**。
- 节拍13（第55章《以盐制盐》）计划：陈默教跛脚刘「**重结晶法把粗盐提纯成雪花精盐**」。

一旦归藏界的人学会了重结晶、能自己「造」出白盐，「这个白不存在」就当场作废，F-017 物证链（卷4「两案并桌」）的根基随之崩。哪怕注释里写「教法不需蓝星货」，**结果**仍然是「归藏界从此有白盐」。这是章纲自己埋的、和节拍1直接打架的雷，必须在开写节拍13前裁决。

### 1.4 附带：盐杀机制的「方案」问题（比物理更该警惕）

两界物理 §5.3 已经把物理补到内部自洽（电解质分流），但它同时锁死了盐杀成立的**三个前置**：敌人必须「张口引气 + 引气峰值 + 换气间隙」三条件同时成立。这意味着：

- 盐杀**高度依赖敌人的配合**——敌人得主动掐诀、把嘴张大、抽到峰值。第2章用「敌人决定一击毙命，所以掐诀引气」勉强补上了，但本质上这是**等对手送窗口**，不是「算死流」主动造窗口。
- 作为章纲明文标定的「**全书名场面**」（第2章「一袋盐杀练气九层」），一个「对方闭口运功就废掉」的杀招，和「算死流=主动算计」的爽点定位是拧着的。读者第二遍读会察觉：这招的成功率建立在敌人配合上。

**这条不是必须改，但必须降级**：把盐杀从「全书名场面/金手指招牌」降为「一次性的、不可复制的、带巨大物证代价的险胜」——第3章其实已经写了「这招本来就再用不了第二回」，但章纲和卖点口径仍把它抬在「全书名场面」的高度，需要下调，否则读者预期和正文事实脱节。

### 2.2 三种具体病灶（有行号可查）

1. **解说员句式**——把主角脑内推理「播报」给读者，而不是让读者自己得出：
   - 第5章 L95-99「他把这几样在心里过了一遍。蜡的成色是同一家……三样凑在一起，指向同一个结论」——观察、清单、结论全部替读者念完。
   - 第1章 L19「他甚至能倒推出这一路的布置」+ L21「陈默在心里把这条线捋了一遍」。
2. **道具/规则说明书**——作者提前讲解设计意图或世界规则：
   - 第5章 L83-87「归藏界的行当里，封样印是『验货』的凭证……」整段是规则讲座。
   - 第4章 L33「真动了手，执法堂先记她一笔……认得这条的，都知道该往哪儿站」+ L113「这仨赌的不是刀，是宗门会为三株灵芝跟士绅撕破脸」——动机与规则旁白。
   - 第1章 L105（原稿）「这梅花扣……是留给『谈崩了』的局面用的」——道具说明书（10 已删半句，但同类句式仍在第5章复发）。
3. **章末总结句**——用内心感悟收尾，等于替读者下结论：
   - 第1章末「十二年了。他等的就是有人先把刀拔出来——」
   - 第2章末「练出来的直觉。」
   - 第4章 L185-195「这不是聪明。这是他这十二年头一回……破一次，他认。」（整整11行的内心结算）

### 2.3 章纲层面的结构性病根（本轮新判定）

旁白/内心戏**不是执行走样，是章纲规定如此**：

- 第1卷章纲·第1节拍分章，明文写：**第3章 =「盐雾物证复盘；『三笔』自察」**——章纲直接要求写一章「复盘+自察」，执行时它只能是陈默一个人坐石头上把账念给自己听（第3章 L21-105 就是这章纲的必然产物）。
- 第4节拍第14章、第5节拍第18章同理：章纲要求「检测仪测出读数低于四年前」「把仪器对准自己」这类**独白/数据戏**，天生没有对白，只有主角一个人 + 一台仪器。
- 陈默人设「算死流/账房」被从**思维底色**写成了**正文形态**：账房是该「少说、用动作证明会算」，不是「把算式全程念给读者听」。

**结论**：要根治，必须在章纲层把「复盘/自察」从「整章独白」改造成「读数 + 一句体感 + 一个动作/对话」的交错结构，并给这些章配「外来者」（对话方），否则刷多少遍文风都会复发。

## 三、整改方案（按优先级）

### P0-1 盐的身份裁决（必须先做，决定后面所有盐戏）

**核心裁决：蓝星盐在归藏界 = 极珍稀的异界走私品，不是自由流通的硬通货。**

理由：①保住了「盐杀名场面」与「F-017 物证链」两个最承重的结构（它们都需要盐「绝无仅有」）；②牺牲的「盐=硬通货」经济线，可由装备名录里现成的「蓝星百货」（白糖/玻璃镜/火柴/辣椒/花露水/钢针）替代——渗透方的经济支柱本来就不该押在盐这一样上；③让陈默「擦盐/埋盐/立四规」的紧张行为第一次有了对等的前提。

**落地改动：**

| 位置 | 现状 | 改为 |
|---|---|---|
| 第1章 L101-107、L113-125 | 抛「二十两+半斤盐」；「边镇人都带盐」「带盐的是常走黑市的」 | 买路钱改**下品灵石**（如二十块）；删「半斤盐当买路钱」与「边镇人都带盐」「带盐=常走黑市」三句——盐从此是陈默藏着不露的秘密武器 |
| 第2章 | 盐是「顺手带的家当」 | 补一句「这袋盐，他进山前就为这一步备下的」——坐实它是专门备的杀器，不是随手抛的货币 |
| 第3章 L43 | 「归藏界没有这种盐」「外头来的」 | **保留**（此时反而成立：盐本就不在归藏界流通） |
| 第4章 L159-163 | 叶青鸾一眼认出「袋子装过盐」；陈默「边镇人都带盐」 | **删两处**——空盐袋不该被一眼认成盐袋 |
| 设定《社会生活与经济》§1.3 | 「蓝星盐=边地黑市硬通货（流通）」 | 改口「黑市珍稀走私品：极少、极贵、只在齐三爷等最高端黑市偶现，寻常边地集市/护卫不识」；「常走黑市的人带盐」不成立 |
| 两界物理 §5.3 / 锚点清单 / 术语规范 | 「黑市硬通货」表述 | 同步改口，并登记「盐=珍稀异界物」为权威口径 + 改写理由 |

**连带裁决（节拍13 的雷）：**「以盐制盐」的重结晶，目标从「提纯成雪花精盐（白）」降为「**去苦、增净、微黄**」——归藏界的土盐可以变好吃、变值钱，但**白仍只属于蓝星盐**。这样既保住养成爽点，又不摧毁「这个白不存在」的物证根基。

### P0-2 盐杀降级（防读者预期与正文事实脱节）

把第2章从「全书名场面/金手指招牌」降为「一次性的、不可复制的、代价巨大的险胜」：

- 章纲总纲 §六.2 与第1卷章纲第1节拍，删「全书名场面」标定，改为「反杀立威（一次性，不可复制）」。
- 卖点口径（简介/卷纲）里「一袋盐杀练气九层」保留为吸睛点，但正文内不再暗示这招能重复。

### P1 旁白/内心戏/流水的章纲层改造

1. **复盘章节改造**：第3章「三笔自察」保留「三笔」这个可视化装置（文风基准已登记为例外），但每笔内部从「连续独白」改为「读数/体感/动作」三段交错，并插入至少一次物理动作或一句自问式短句打断（10 §5.2 已有示范，直接套用）。
2. **给纯独白章配「外来者」**：第14、18、20章的连续独白块（721/1307/1467字），切碎时优先改成「陈默 + 一个活人」的对话/互动，而非「陈默 + 仪器」的单人推演。
3. **删三种句式**（通刷，可做机检）：
   - 解说员：「他把X在心里过了一遍」「三样凑在一起，指向……」「他甚至能倒推出」→ 删，让细节自己说话。
   - 说明书：「X是Y的凭证/规矩」「这设计是留给X用的」→ 删，兑现瞬间再显现。
   - 章末总结：「十二年了，他等的就是……」「这不是聪明，是……」→ 换成动作或对话收尾。
4. **账房人设复位**：陈默的「算死流」通过极简动作+一句冷幽默台词+一次精准破局来流露（文风基准 §四 范文「空壶倒两次」即此），不把算式念给读者。

## 六、问题三（2026-10-07 增补）：货币单位与「修士怕凡人」

### 6.1 货币：三轨制没错，错在「执行跨轨」

设定《社会生活与经济》§1.1 是**三轨并行**，本身自洽且更真实：
- 铜钱/银两（文/两）＝凡人社会（归藏界有庞大凡人，凡人用铜银天经地义）
- 灵石（下品/中品）＝修士圈
- 盐＝黑市（本轮已裁决删除其货币职能）

**「修仙界为什么用铜板」的答案是：铜板是给凡人用的，不是给修士用的。** 问题不在铜板存在，而在三处「执行跨轨」：

| # | 位置 | 症状 | 修法 |
|---|---|---|---|
| 1 | 第1章「二十两」 | 修士对修士买路钱用**银两**（错轨） | 改下品灵石（本轮盐整改顺带） |
| 2 | 第17章 L305「涨七文」 | 陈默心算把**灵石涨跌说成铜钱（文）**，且与同段 L301「近两成」自相矛盾 | 删/改「近两成」；设定§1.2已登记此教训但正文没改干净 |
| 3 | 通篇「块/文/两」混算 | 心算跨轨、换算残留 | 严守「块仅对话层，心算一律文/两/灵石」 |

**陈默「跑单帮行商」掩护在凡人层，日常用铜银是对的**——这正是他藏身的方式。要防的是「修士场合漏出铜银/文」这种错轨，不是把铜板赶尽。若你确实嫌铜板碍眼，可选「淡化」：行商线多用「散货/灵液/灵石」结算，减少具体文数出现（改动更大，见 §六.4 决策）。

### 6.2 怕凡人：文本嘴上说「不是打不过」，动作却写「被逼退」

第4章现在的矛盾：L29「练气五层要动手，这仨躺下用不上一息」、L33「不是打不过」——但 L37「她就这么一步一步往后退，退到树根上，退无可退」。

**嘴上否定、动作肯定。** 一个洗筋伐骨的练气5层，被练气1层+两个凡人「挤得一步一步后退」，物理上仍是被凡人压制的观感，与《世界观》§2.2「练气=洗筋伐骨、肉身远超凡人」、《社会生活与经济》§6.2「凡人敬畏修士如神明」打架。

**修法**：把「退」从「被物理推挤」改成「主动避让」——她不退，或退也只是护着药、避着冲突，张力落在「她要不要破例还手」，不落在「她能不能顶住」。示范：删「一步一步往后退」，改成她站着不动，攥铲的手指节发白；横肉汉子伸手来夺药篓，她只把药篓往身后一别——那一下快得像本能，比她自己还先反应过来。

### 6.3 连带：把「敬畏」还给凡人层

第4章「凡人敢动手」虽已用「士绅靠山+地契」补了理由，但整段读感仍是「凡人不怕修士」。建议在第4章补一句**敬畏的可见细节**：三个汉子其实心里发虚（攥柴刀的手在抖、眼神不敢正对姑娘的眼睛、走的是绕着她外圈的路）——他们赌的是「宗门不管」，不是「打不过她」。这样「怕」的是宗门与士绅的账，不是肉身的强弱，两处都不塌。
