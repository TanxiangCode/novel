# 卷4相持段战果密度表（第15-21拍·防塌陷专用）

> **建立**：2026-09-27（执行计划 P0-1）
> **依据**：`大纲/第4卷大纲.md` 第四阶段 + `大纲/第4卷章纲.md` 第15-21拍
> **问题**：架构报告判定本段"全部是背景铺设，没有独立事件"——男频读者对"背景铺设"耐心极低，连续30章纯算计会弃书
> **解法**：**每2章一个具体战果**，且战果形态必须轮换（抓人/拔人/清剿/反转/交易/识破/代价），不能让读者"看腻一种赢法"

---

## 一、判据（表完成后须同时满足）

1. **每2章可指认一个"看得见的战果"**（本表逐行给出）
2. **战果形态轮换**——7拍内不重复同一种赢法
3. **不是全部由陈默赢**——须有"他赢的代价""他没赢的""别人替他赢的"
4. **第17+拍（翻译者的胜利）是段内最大战果**——相持段的正峰

## 三、战果形态轮换校验（防看腻一种赢法）

| 形态 | 出现次数 | 具体位置 |
|------|---------|---------|
| 情报/推算 | 1 | 15拍·他算消化容量 |
| 惩戒（制度） | 1 | 15拍·北国倒卖配额 |
| 压制/博弈 | 1 | 15拍·背书底线 |
| 揭露（道德） | 1 | 16拍·内部争议 |
| 代价（私人） | 1 | 16拍·沈铁柱"家里定了亲" |
| 救援→同盟 | 1 | 17拍·救鹰→篝火 |
| 反噬（负） | 1 | 17拍·鹰举报失败 |
| **翻译（本段正峰）** | 1 | **17+拍·翻译者的胜利** |
| 外溢（反派） | 1 | 18拍·陆衡用账法 |
| 静默（留白） | 1 | 18+拍·宋晚棠独处 |
| 物证 | 1 | 19拍·灵木枝条 |
| 追问（学术） | 1 | 19拍·相关性 |
| 拐点（危机） | 1 | 20拍·加速度拐点 |
| 汇流（悬念） | 1 | 20拍·守缺真人下山 |
| 攥把柄（反） | 1 | 21拍·秦无涯/陆衡 |

**校验结论**：15个战果，形态无一重复 ✓。其中：
- **陈默赢的**：4次（推算/翻译/物证/追问）——占27%，**不过半**
- **制度赢的**：2次（惩戒/同盟后的体制）——背景力量也有赢
- **别人赢/反派赢的**：3次（鹰救援/陆衡外溢/陆衡被攥）——**主角不是唯一主角**
- **代价/负/痛/静默**：6次（沈铁柱/鹰反噬/翻译代价/宋晚棠/相关性沉默/陆衡被攥）——**占40%**

> **关键设计**：本段不是"主角一路赢"，而是"赢法轮换 + 代价交织"。这既防塌陷，也防"同一种赢法看腻"（架构报告指出的核心爽点同质化问题）。

## 四、段内三波节奏（读者的"三起三落"）

```
第15-16拍 ▁▃  起：情报推算→惩戒→道德争议（沈铁柱落）
第17拍   ▅▅  最高：救鹰→同盟→**但鹰反噬**（起后立刻落）
第17+拍  ▇▇  段内正峰：翻译者的胜利（不露面赢最大的一局）
第18拍   ▃▁  落：陆衡外溢（反）+ 宋晚棠独处（静默）
第19-20拍 ▂▄ 缓升：物证→追问→**但拐点是坏消息**（加速下坠）
第21拍   ▃▅  收：陆衡被攥把柄（反派的反）+ 两界数据即将握手（大钩）
```

**节奏判据**：本段**没有一个连续3章的高爽**——每个爽点之间必有代价/静默/反噬垫底。**这是防塌陷的核心。**
