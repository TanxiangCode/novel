# 卷5恶化曲线表（2033-2040·书名《消失的灵气》正名之卷）

> **建立**：2026-09-27（执行计划 P0-2）
> **依据**：`大纲/第5卷大纲.md`（含2026-09-27卷纲优化条款）+ `设定/科技/两界物理与科学修仙模型.md` §1.1-1.3
> **书名咬合**：卷名"灵气衰逝"≈书名"消失的灵气"。本卷20节拍要构成**一条清晰的逐年恶化曲线**
> **核心手法**：用**同一组指标的逐年读数**承载书名，而非反复说"在衰减"（后者是台词，前者才是数据）

---

## 一、判据

1. **每年至少一处"同一指标的恶化读数"**——指标要有连续性，跨年可对比
2. **恶化是加速的**——不是匀速下滑，是逐年加速下坠（呼应卷4末"加速度拐点"）
3. **恶化落到人上**——数据最终要变成可感的代价（药农绝收的远亲、找不到师父的年轻修士）
4. **80年终末临界点**（2110年代·全洲灵脉跌破自我凝灵临界阈值·修仙断代）要能倒推出本卷的位置

## 四、恶化的加速曲线（可视化）

```
加速度感（年降幅倍数）
  │
  │                                    ╱ 2038-40：封堵派定强封日
  │                              ╱────
  │                        ╱───── 2037：真录·跌破六成
  │                  ╱─────       2036：原罪实锤·腰斩
  │            ╱─────             2035：出丹率降2成
  │      ╱─────                   2034：出丹率降1成半
  │ ────                         2033：拐点显形·降1成半
  └──────────────────────────────────────────
        匀速下滑区（认知期）    加速下坠区（危机期）
        ← 卷1-4，读者只知道"在降" →  ←卷5，读者知道"要完了"→
```

> **关键设计**：**2033-2034 是"匀速"，2035 之后才是"加速"**——这呼应卷4末捕捉到的"加速度拐点"（2032）。恶化不是一开始就吓人的，是**读者跟着数据一起看它变快**。
