# 数量账登记表

> **依据**：skill `SKILL.md` §7.3.4 数量账纪律（2026-09-29 立）
> **为什么单独立表**：§7.2 查的是「与设定库冲突」，§7.4 查的是「物品复活/身份生人化」——**跨章加减乘除是否守恒，任何现有规则都不管**。这是本书最容易漏、且**机检全过**的一类错（见下方事故）。
> **规则**：凡正文出现**可累加的量**（重量/银钱/颗数/余量/里数/次数），首次出现即登记，此后每次动用必须能在本表倒推回去。

## 一、本书换算基准（算前必查）

| 类别 | 换算 | 纪律 |
|---|---|---|
| 重量 | **1斤 = 16两**；1斤 ≈ 600克 | 斤↔两必须先换算，**禁止心算混用** |
| 银钱 | 1块(下品灵石) ≈ 5两 ≈ 5000文 | **「块」只许出现在对话层**，叙述与心算一律用文/两/灵石（术语规范 §5.1） |
| 三等血芝 | 4.5块一两 | 全书基准价，出现任何血芝算式前先对这条 |
| 时间 | 1更 ≈ 2小时；1盏茶 ≈ 10-15分钟；1炷香 ≈ 30-45分钟 | 见术语规范 §5.1 |

## 四、写作时自检三问

1. **这个数在第几章出现过？** → 翻本表，核对是否守恒
2. **单位换过了吗？** → 斤↔两、文↔两↔块，不同轨不混算
3. **这次是收入还是支出？** → 收入加、支出减，方向别搞反（**第19章"涨了就是175块"就是方向搞反**）

> 机检脚本只能列出待核清单，**守恒必须人工心算复核**。本书斤/两双轨 + 文/两/块三轨，是最容易算错的地方。
