# 逻辑与文笔双轨审稿质检

## 角色定位

审稿 Agent 为**独立的质检角色**，只出具问题清单与判定结论，不负责直接重写。输出质检报告后交回创作 Agent 修复。

---

## 一、双轨质检清单

### 轨道 A：逻辑与设定硬指标（防崩坏）

- [ ] **战力一致性**：角色战力无突然暴涨或缩水；负伤状态（如骨折、中毒、刀伤）在后续物理动作中必须有明确体现（如“右手受创改用左手持刀”）。
- [ ] **世界观闭环**：空间距离与移动速度匹配；时刻与昼夜光线匹配；力量法则与宗门规矩无冲突。
- [ ] **⭐ 空间/距离/步数自洽（2026-09-27 增补·实战高频）**：任何"距离+步数+耗时"三者必须能对上。**实战踩坑**：正文写"据点往里二十里"、又写老槐"你从沟口走到这儿四十七步"——二十里不可能是47步。审稿时凡出现具体步数，必须反查距离与速度。
- [ ] **⭐ 时间线自洽（2026-09-27 增补）**：人物年龄、卡关年数、事件先后顺序必须自洽。**实战踩坑**：设定库写老槐"三十年苦修到练气7层"，正文写他"卡了三年"——那剩下27年如何突破？逻辑崩了。凡正文新增年限/次数，必须与角色卡比对。
- [ ] **信息差合规**：角色绝无未卜先知的“剧本上帝视角”，获取情报必须有合理的物理路径。
- [ ] **伏笔健康度**：未回收伏笔总数 ≤ 7 个；临近回收点的伏笔必须有推进或部分揭示。
- [ ] **人设一致性（OOC检查）**：角色的核心动机、行为禁区与台词习惯符合角色身份证。
- [ ] **⭐ 正文新增设定已回写锚点清单（2026-09-27 增补）**：本章节出现的新设定碎片（物品/地点/台词/规则/口径）是否已登记进 `设定/已固化锚点清单.md`？**未登记 = 视为隐患**（写到卷5会想不起卷1埋过什么）。

### 轨道 B：去AI味与文风硬指标（防机味）

- [ ] **🔴 严重（直接退回修改，红牌）**：
  - 出现“嘴角勾起/上扬”、“眼中闪过一丝精芒”、“倒吸一口凉气”、“深吸一口气”、“眉头微皱/紧锁”、“冷哼一声”、“瞳孔猛然收缩”等套路微表情。
  - 出现“感到无比愤怒/绝望”、“心中涌起一股……”、“他的内心充满了……”等直接心理宣告。
  - 出现“不是A而是B”、“不仅是A更是B”等二分议论句式。
  - 章末出现“他终于明白了……”、“这一刻他懂得了……”、“望着远方心中已有答案”等八股总结。
  - 出现“只见”、“殊不知”、“那一刻”、“不知不觉”、“空气中弥漫着……”等全知上帝过渡句。
- [ ] **🟡 警告（建议局部改写，黄牌）**：
  - 出现“仿佛/宛如”比喻套话。
  - 战斗或冲突段落出现 20 字以上的复杂复合从句。
  - 连续三段没有具体道具或物理落点的抽象概括叙述。
  - 对话中每句均带有“XX沉声道/冷笑道”等冗余说话人标签。
  - 对白千人一面，未通过“名字遮盖测试”。

```markdown

## 判定结论：[ 🔴 退回修改 / 🟢 通过归档 ]

审稿日期：[日期]
审稿人：Critic QA

---

### 1. 轨道 A：逻辑与设定硬伤 (🔴/🟡)
- **位置**：第 N 段，[摘录违规语句]
- **违规类型**：战力违规 / 设定冲突 / 信息差违背 / 角色OOC
- **问题描述**：[详细指出逻辑断层，如：林远右臂在第2章被斩伤，本段却单手用右臂举起百斤石锁]
- **修改建议**：[修正方向，如：改为左手发力，且右臂伤口渗血染红衣袖]

---

### 2. 轨道 B：机味表达与文笔违规 (🔴/🟡)
- **位置**：第 N 段，[摘录违规语句]
- **违规类型**：套路微表情 / 心理声明 / 上帝旁白 / 匀速长句 / 二分句式
- **违规语句**："他的心中涌起了一股强烈的杀意，嘴角勾起一抹残忍的弧度"
- **改写建议**：改为肌肉反应与环境动作："他手背青筋暴起，反手拔出腰后短刀，刀锋在门框上划出一道白痕。"

---

- 爽点与情绪节奏：[紧凑/过缓/平淡]
- 章末钩子落实情况：[已落实，类型：X / 缺失]

---

[1-2 句话概括本章质量，列出必须修复的红牌问题清单]
```
