# 伏笔与状态追踪规范

## 使用场景

每章创作前读取状态文件，创作完成并审稿通过后立即更新。防止长篇连载时设定漂移、人设崩塌、伏笔遗忘与道具错乱。

---

## 一、角色实时状态表 (`state/character-state.md`)

> 每章完成后必须更新。

```markdown
# 角色实时状态表

> 最后更新：第[N]章写完后

| 角色 | 当前具体位置 | 生理健康/伤势状态 | 核心即时目标 | 当前持有道具 | 最近关键物理事件 |
|------|-------------|-------------------|-------------|-------------|----------------|
| 林远 | 青云城·同福客栈 | 右手虎口震裂(轻度) | 查验密信暗记 | 半块玉佩、短刀 | 第3章客栈击退黑衣人 |
| 苏婉 | 皇宫·淑芳殿 | 偶感风寒 | 获取帝王批文 | 藏毒银簪 | 第3章深夜密见国师 |
| 赵恒 | 未知 | 失踪/生死未卜 | - | 门规戒律残卷 | 第2章后失联 |
```

### 字段填写铁律
1. **生理健康/伤势状态**：必须精确到身体部位与创伤类型（如“右臂刀伤深及见骨”、“经脉滞涩”），下一章正文必须体现动作限制。
2. **核心即时目标**：角色当下最迫切要做的事（不等于终极愿景）。
3. **持有道具**：道具增减必须注明物理状态（完好/破损/耗尽）。

## 二、伏笔追踪表 (`state/foreshadowing.md`)

> 控制伏笔生命周期，防止“烂尾”与“遗忘”。

```markdown
# 伏笔追踪表

> 最后更新：第[N]章写完后

| 编号 | 伏笔核心内容 | 埋设章节 | 计划回收 | 当前状态 | 回收章节 | 备注与线索关联 |
|------|-------------|---------|---------|---------|---------|----------------|
| F-001 | 玉佩上的半截刻字 | 第1章 | 第8章 | 已埋设 | - | 需与赵恒持有部分拼合 |
| F-002 | 老王倒茶时的截脉手法 | 第3章 | 第6章 | 已埋设 | - | 暗示其前禁军教头身份 |
| F-003 | 赵恒失踪前的最后行踪 | 第2章 | 第5章 | 已回收 | 第5章 | 回收方式：在密室找到其血书 |
| F-004 | 皇帝咳嗽手帕上的黑血 | 第3章 | 第12章 | 部分揭示 | - | 暗示帝王身中奇毒 |
```

### 伏笔管理铁律
1. **上限熔断**：未回收伏笔总数（`已埋设` + `部分揭示`）必须控制在 **7 个以内**。一旦达到 7 个，后续 2 章内必须强制安排回收或部分揭示。
2. **间距规则**：小伏笔 3–5 章内回收，中伏笔 10–20 章，大伏笔可跨卷但需在卷末做阶段性交代。
3. **回收方式合规**：严禁“机械降神”式突然揭秘，回收必须由角色通过物理证据或行动达成。

## 五、断更恢复检查清单

当暂停创作后恢复时，严格按此清单读取上下文以恢复语感与设定：

```
- [ ] 1. 读取 settings/style-benchmark.md：重新复习句式节奏与 Few-Shot 样本，校准文风语感
- [ ] 2. 读取 state/character-state.md：确认各角色的具体位置、生理伤势与即时目标
- [ ] 3. 读取 state/foreshadowing.md：筛选未回收伏笔，检查本章是否有待回收条目
- [ ] 4. 读取 state/inventory.md：确认角色随身携带的装备道具及其状态
- [ ] 5. 读取 settings/characters/[涉及角色].md：重温各角色的语言锚点、行为锚点与行为禁区
- [ ] 6. 读取最近 2 章正文：恢复叙事节奏与氛围连贯性
- [ ] 7. 读取 outline/chapter-[N].md：确认本章核心主线任务与场景规划
```
