# 伏笔与状态追踪

## 使用场景

每章创作前读取状态文件，创作后立即更新。防止长篇连载时设定漂移、人设崩塌、伏笔遗忘。

---

## 一、角色状态表

存放在 `state/character-state.md`。每章写完后更新。

### 表格模板

```markdown
# 角色实时状态表

> 最后更新：第[N]章写完后

| 角色 | 位置 | 健康 | 心理状态 | 当前目标 | 持有道具 | 最近关键事件 |
|------|------|------|---------|---------|---------|------------|
| 林远 | 青云城·客栈 | 右臂刀伤(未愈) | 警惕/隐藏身份 | 找到密信线索 | 玉佩(半块)、短刀 | 第3章被追杀 |
| 苏婉 | 皇宫·淑芳殿 | 健康 | 焦虑 | 获取帝王信任 | 毒药(藏于簪中) | 第3章夜见皇帝 |
| 赵恒 | 未知 | 失踪 | ? | 未知 | 无 | 第2章后失踪 |
```

### 更新规则

1. **位置**：本章结束时角色所在地点
2. **健康**：受伤/中毒/恢复中/健康/垂死
3. **心理状态**：用1-2词概括当前情绪
4. **当前目标**：角色此刻最想达成的事
5. **持有道具**：增减变化需注明来源（第N章获得/失去）
6. **最近关键事件**：最近一次影响角色的重要事件

## 二、伏笔追踪表

存放在 `state/foreshadowing.md`。每章写完后更新。

### 表格模板

```markdown
# 伏笔追踪表

> 最后更新：第[N]章写完后

| 编号 | 伏笔内容 | 埋设章节 | 计划回收章节 | 当前状态 | 回收章节 | 备注 |
|------|---------|---------|------------|---------|---------|------|
| F-001 | 林远玉佩上的刻字 | 第1章 | 第8章 | 已埋设 | - | 刻字内容："天衍四九" |
| F-002 | 苏婉簪中毒药来源 | 第2章 | 第6章 | 部分揭示 | - | 第3章揭示毒药类型 |
| F-003 | 赵恒失踪前的最后行踪 | 第2章 | 第5章 | 已回收 | 第5章 | 回收方式：在密室找到其日记 |
| F-004 | 皇帝咳嗽时手帕上的血迹 | 第3章 | 第12章 | 已埋设 | - | 暗示帝王病重 |
```

### 伏笔状态说明

| 状态 | 含义 |
|------|------|
| 已埋设 | 伏笔已写入正文，尚未回收 |
| 部分揭示 | 给出了部分线索但未完全回收 |
| 已回收 | 伏笔已完全回收，揭晓答案 |
| 已废弃 | 因剧情调整放弃，需在备注注明原因 |

### 伏笔管理规则

1. **每个伏笔必须有计划回收章节**，不允许"先埋了再说"
2. **回收间距控制**：小伏笔3-5章内回收，中伏笔10-20章，大伏笔可跨卷但需在卷末有阶段性揭示
3. **同时未回收伏笔不超过7个**，超过需优先回收部分
4. **回收方式不能与埋设矛盾**，回收前检查角色状态表和世界观设定

## 四、时间线记录

存放在 `settings/timeline.md`。

### 格式

```markdown
# 时间线

## 第N卷时间线

| 时间 | 事件 | 涉及角色 | 章节 |
|------|------|---------|------|
| 建元十五年·春 | 林远抵达青云城 | 林远、客栈掌柜 | 第1章 |
| 同日·夜 | 苏婉夜见皇帝 | 苏婉、皇帝 | 第1章 |
| 次日·晨 | 林远发现密信线索 | 林远 | 第2章 |
| 次日·午 | 赵恒失踪 | 赵恒 | 第2章 |
```

### 记录规则

1. 用相对时间（次日/三天后）或绝对时间（建元十五年春）均可，但全卷统一
2. 同一天发生的事件标注"同日"
3. 跨章事件确保时间连贯（角色不可能同时出现在两地）

## 五、断更恢复检查清单

当暂停创作后恢复时，按此清单操作：

```
- [ ] 读取角色状态表，确认每个角色当前状态
- [ ] 读取伏笔追踪表，确认未回收伏笔
- [ ] 读取时间线，确认当前时间节点
- [ ] 读取道具持有表，确认关键道具归属
- [ ] 读取涉及角色的 settings/characters/[角色名].md，
      重新确认各角色的语言锚点和行为锚点（防止断更后对话风格飘移）
- [ ] 读取最近3章正文，恢复语感和风格
- [ ] 读取当前卷纲，确认接下来要写的内容
```
