# 小说全流程创作引擎

整合工程化长篇管理 + 动作分镜解耦生成 + 物理白描去机味质检的完整创作系统。

## 核心流程总览

```
设定与文风建库 → 卷纲规划 → 章纲拆解 → 场景卡组装(绑定物理交互) → 动作分镜生成 → 感官正文扩写 → 去AI味深度润色 → 状态归档 → 双轨逻辑审稿
```

每个阶段有明确输入输出，前一阶段的输出是后一阶段的输入。任何阶段可回溯修改。

---

## 阶段一：设定与文风建库

在开始创作前，将世界观、文风基准、角色、时间线、势力关系分文件存储，防止长篇连载时设定漂移与文风机化。

### 文件结构

```
novel-project/
├── 设定/
│   ├── 世界观.md             # 世界观：地理/历史/力量体系/社会结构
│   ├── 文风基准.md           # 文风基准库：句式节奏/五感标杆/Few-Shot样本（技能内参考件见 style-benchmark.md）
│   ├── 设定汇总目录.md       # 设定体系总目录：已有/待建文档登记与优先级
│   ├── 角色/
│   │   ├── [角色名].md        # 每个主要角色独立建档（含语言/行为锚点）
│   │   └── ...
│   ├── 全文总纲.md           # 时间线：大事件按时间排列
│   └── 势力关系图.md         # 势力与利益冲突图
├── 大纲/
│   ├── 第[N]卷大纲.md        # 每卷大纲
│   └── 第[N]卷章纲.md        # 每卷章纲
├── 正文/
│   ├── 第[编号]章-[章名].md  # 最终定稿正文
│   └── ...
└── 状态/
    ├── 角色状态追踪.md        # 角色实时状态表（见 memory-tracker）
    ├── 伏笔追踪表.md          # 伏笔追踪表
    └── 道具持有表.md          # 道具与装备持有表
```

### 角色身份证模板

每个角色文件必须包含以下结构（详见 [reference.md](reference.md) 的"角色身份证"章节）：

```markdown
# [角色名]

## 基础信息
- 年龄/性别/身形特征
- 身份/职业/阵营
- 核心动机（驱动角色一切行动的根本欲望，1句话）

## 气质与识别锚点（杜绝千人一面）
### 视觉锚点（3个标志性视觉特征）
1. [特征1：如"洗得发白的青布袍，袖口用麻绳扎紧"]
2. [特征2：如"右眉骨有一道寸许长的白疤"]
3. [特征3：如"看人时习惯微微低头看地面"]

### 语言锚点（说话方式与台词习惯）
- 句式习惯：[如：短句为主，极少使用连接词，从不说反问句]
- 禁用表达：[如：绝对不说成语，从不自称"在下"]
- 用词偏好与口头习惯：[如：粗俗/简洁/说话前习惯停顿半拍]

### 行为锚点（3个标志性动作）
1. [动作1：如"紧张时下意识摩挲短刀刀柄缠绳"]
2. [动作2：如"生气时反而变得极其安静、语速变慢"]
3. [动作3：如"说谎前会不自觉地先咽一口口水"]

## 人物弧光与成长路线
[角色从开始到结局的变化轨迹与战力变化]

## 行为禁区（绝对不可违背的底线）
- [如"绝不对妇孺拔刀；答应的事必须做到"]
```

## 阶段二：卷纲规划

为每卷创建宏观大纲与情绪曲线。

### 卷纲模板

```markdown
# 第[N]卷：[卷名]

## 卷级核心目标
[本卷要解决的核心利益争夺/达成的核心战略目标]

## 爽点节奏与情绪曲线（网文向）
| 章节区间 | 节奏定位 | 核心剧情事件 | 读者心理预期 |
|----------|----------|--------------|--------------|
| 1-3章    | 引入-钩子 | 遭遇外部冲突，设立即时悬念 | 期待破局 |
| 4-6章    | 压抑-蓄力 | 困境与阻碍升级，信息差收紧 | 代入紧迫感 |
| 7-9章    | 爆发-爽点 | 逆转/突破/打脸/资源获取 | 情绪释放 |
| 10-12章  | 余波-新钩 | 利益收束 + 抛出更高维度冲突 | 期待下一卷 |

## 关键转折点
1. [转折点1]：触发条件 → 连锁反应
2. [转折点2]：触发条件 → 连锁反应
```

---

## 阶段三：章纲拆解

将卷纲中的每章拆解为可执行的章纲。

### 章纲模板

```markdown
# 第[N]章：[章名]

## 本章基础信息
- POV角色：[视角角色]
- 目标字数：约[N]字
- 在卷中位置：[开篇/发展/高潮/收束]
- 本章主线进度：[推进的核心事实]

## 场景规划（2-3个场景）
1. 场景一：[出场人物 / 空间地点 / 核心对抗事件]
2. 场景二：[出场人物 / 空间地点 / 核心对抗事件]
3. 场景三：[出场人物 / 空间地点 / 核心对抗事件]

## 章末钩子
[类型：信息中断/危机降临/身份揭示/道具异动等，见 reference.md "悬念钩子十三式"]

## 本章应推进的伏笔
- 埋设：[伏笔编号及内容]
- 推进/回收：[伏笔编号及处理方式]
```

---

## 阶段四：场景卡组装

写正文前必须将每章拆解为 2–3 张场景卡（单卡对应 800–1500 字），**必须绑定环境道具交互与物理生理载体**，详见 [scene-card-crafter.md](scene-card-crafter.md)。

---

## 阶段五：正文两步解耦生成（核心突破）

**绝对禁止**在单次生成中同时处理“推演复杂剧情”与“雕琢文学细节”。大模型必须强制执行两步法：

### 步骤 1：生成动作分镜流（Action Script）
输出无任何形容词修饰的纯物理动线与骨架台词：
```markdown
- [林远推开虚掩的木门]
- [视线落点：桌角青花茶盏还在冒热气，椅面有轻微摩擦痕迹]
- [动作：反手合上门栓，右手拇指顶开刀鞘半寸]
- [台词-短句] 林远："出来。"
- [反馈：屏风后传来衣料摩挲声与轻微的铁器碰撞声]
```

### 步骤 2：感官正文扩写（Sensory Expansion）
严格对照 `设定/文风基准.md` 的文风基准与 `de-ai-humanizer.md` 的禁用清单，将动作分镜流扩写为正式正文：
- 落实白描与五感交互（温度、气味、触感、声音、光影）；
- 严格执行单句长度压制（冲突段 ≤10 字，普通叙事 ≤20 字）；
- 执行白描对白（省略冗余说话人标签，穿插动作交代说话者）。

---

## 阶段六：去AI味深度润色

正文扩写后必须经过深度扫描与物理化置换，详见 [de-ai-humanizer.md](de-ai-humanizer.md)。

### 核心禁令与扫描（命中即改）
- 🔴 **严禁套路微表情**：嘴角勾起/上扬、眼中闪过一丝、倒吸凉气、瞳孔收缩、深吸一口气、冷哼一声；
- 🔴 **严禁心理声明**：心中涌起、感到无比愤怒/绝望、内心充满了、前所未有的压力；
- 🔴 **严禁套路过渡与上帝旁白**：只见、殊不知、那一刻、不知不觉、刹那间、空气中弥漫着；
- 🔴 **严禁二分议论句式**：不是A而是B、不仅是A更是B、与其说A不如说B；
- 🔴 **严禁章末感悟八股**：他终于明白了一切、这一刻他懂得了、望着远方心中已有答案；
- 🔴 **严禁空洞宣传腔**：前所未有的力量、惊天动地、震撼了整个X界、恐怖如斯。

---

## 阶段七：状态归档

每章写完后立即更新状态文件，详见 [memory-tracker.md](memory-tracker.md)。

### 必须更新的文件
1. **角色状态表** (`状态/角色状态追踪.md`)：更新角色位置、生理伤势、即时目标
2. **伏笔追踪表** (`状态/伏笔追踪表.md`)：记录埋设/推进/回收（未回收总数控制在 ≤7 个）
3. **道具持有表** (`状态/道具持有表.md`)：更新装备与道具物理状态及归属
4. **时间线** (`设定/全文总纲.md`)：追加本章发生的客观事件

---

## 阶段八：双轨逻辑审稿

每章或每卷完成后进行独立质检，详见 [critic-qa.md](critic-qa.md)。

### 双轨审查维度
1. **轨道 A（设定与逻辑硬指标）**：战力一致性（无无端突变/伤势体现）、世界观闭环、信息差合规、伏笔健康度。
2. **轨道 B（文风与去机味硬指标）**：
   - 🔴 **严重（直接退回）**：命中 40+ 禁用套话/微表情/心理声明/章末八股；
   - 🟡 **警告（建议改写）**：战斗段长句堆叠、缺少环境实物落点、对白千人一面未通过名字遮盖测试。

## 快速使用指南

| 用户需求 | 执行动作 |
|---------|---------|
| "我想写一部小说" / "我有个故事想法" | 先执行 [reference.md](reference.md) "三层递进创意提炼" → 建立设定库与文风基准库（阶段一） |
| "帮我写第N章" | 读取状态与文风基准 → 拆解场景卡（阶段四） → **生成动作分镜流（阶段五-1）** → **感官扩写（阶段五-2）** → 深度润色（阶段六） → 双轨审稿（阶段八） → 状态归档（阶段七） |
| "润色这段文字" | 直接执行阶段六去AI味深度润色，严格执行物理化置换与断句手术 |
| "检查这章有没有问题" | 直接执行阶段八双轨逻辑审稿，出具红黄牌质检报告 |
| "追踪伏笔" / "哪些伏笔没回收" | 读取 `状态/伏笔追踪表.md`，筛选状态并检查是否超标（>7个触发预警） |
| "规划下一卷" | 执行阶段二卷纲规划，绘制爽点节奏表与关键转折点 |
| "停了一段时间，要继续写" | 执行 [memory-tracker.md](memory-tracker.md) 断更恢复检查清单 |
