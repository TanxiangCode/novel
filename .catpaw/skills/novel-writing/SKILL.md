# 小说全流程创作引擎

整合多 Agent 协作流 + 网文节奏控制 + 风格化质检 + 长篇工程化管理的完整创作系统。

## 核心流程总览

```
设定建库 → 卷纲规划 → 章纲拆解 → 场景卡组装 → 正文生成 → 去AI味润色 → 状态归档 → 逻辑审稿
```

每个阶段有明确输入输出，前一阶段的输出是后一阶段的输入。任何阶段可回溯修改。

---

## 阶段一：设定建库

在开始创作前，将世界观、角色、时间线、势力关系分文件存储，防止长篇连载时设定漂移。

### 文件结构

```
novel-project/
├── settings/
│   ├── worldview.md          # 世界观：地理/历史/力量体系/社会结构
│   ├── characters/
│   │   ├── [角色名].md        # 每个主要角色一个文件
│   │   └── ...
│   ├── timeline.md           # 时间线：大事件按时间排列
│   └── factions.md           # 势力关系图
├── outline/
│   ├── volume-[N].md         # 每卷大纲
│   └── chapter-[N].md        # 每章章纲
├── chapters/
│   ├── ch-[编号]-[章名].md   # 正文
│   └── ...
└── state/
    ├── character-state.md     # 角色实时状态表（见 memory-tracker）
    ├── foreshadowing.md       # 伏笔追踪表
    └── inventory.md           # 道具持有表
```

### 角色身份证模板

每个角色文件必须包含以下结构（详见 [reference.md](reference.md) 的"角色身份证"章节）：

```markdown
# [角色名]

## 基础信息
- 年龄/性别/外貌特征
- 身份/职业
- 核心动机（驱动角色行动的根本欲望）

## 气质锚点
### 视觉锚点
[3个标志性视觉特征：如"总穿灰袍"、"左脸刀疤"、"说话时眯眼"]

### 语言锚点
[口头禅/说话节奏/用词偏好：如"从不说不"、"短句多"、"爱用比喻"]

### 行为锚点
[标志性动作/习惯：如"紧张时搓手指"、"愤怒时反而安静"]

## 人物弧光
[角色从开始到结局的变化轨迹]

## 关系网
[与其他角色的关键关系]
```

## 阶段二：卷纲规划

为每卷创建宏观大纲。

### 卷纲模板

```markdown
# 第[N]卷：[卷名]

## 卷级目标
[本卷要解决的核心冲突/达成的核心目标]

## 爽点节奏（网文向）
| 章节区间 | 节奏 | 内容 |
|----------|------|------|
| 1-3章 | 起伏-钩子 | 引入冲突，章末留悬念 |
| 4-6章 | 压抑-蓄力 | 困境升级，读者代入感 |
| 7-9章 | 爆发-爽点 | 逆转/突破/打脸 |
| 10-12章 | 余波-新钩 | 收束+抛出新悬念 |

## 关键转折
1. [转折点1]：触发条件 → 后果
2. [转折点2]：触发条件 → 后果
```

---

## 阶段三：章纲拆解

将卷纲中的每章拆解为可执行的章纲。

### 章纲模板

```markdown
# 第[N]章：[章名]

## 本章信息
- 视角：[POV角色]
- 时长：约[N]字
- 在卷中位置：[开篇/发展/高潮/收束]

## 核心目标
[本章要推进的剧情/要解决的问题]

## 场景列表（见 scene-card-crafter）
1. 场景一：[简述]
2. 场景二：[简述]
3. 场景三：[简述]

## 章末钩子
[本章结尾的悬念/反转，类型参考"悬念钩子十三式"]

## 本章应推进的伏笔
- [伏笔编号]：[状态：埋设/部分揭示/回收]
```

## 阶段四：场景卡组装

写正文前必须将每章拆成场景卡，详见 [scene-card-crafter.md](scene-card-crafter.md)。

### 场景卡核心要素（每张卡对应约800-1500字）

```
场景卡 #[N]
- POV：[视角角色]
- 地点/时间：[场景环境]
- 角色核心目标：[这个场景中主角想要什么]
- 阻碍与对抗：[什么阻止了目标达成]
- 信息差：[谁知道什么/谁不知道什么]
- 情绪走向：[从X到Y，如"平静→紧张→释放"]
- 出场人物：[在场角色列表]
- 本章伏笔操作：[埋设/回收哪个伏笔]
```

## 阶段五：正文生成

基于场景卡逐场景生成正文。

### 写作规则

1. **先动作后描写**：以角色动作或对话开场，避免大段环境描写
2. **感官优先**：用视觉/听觉/触觉/嗅觉/味觉推进，不堆砌形容词
3. **信息差驱动**：利用"谁知道什么"制造张力和反转
4. **章末必留钩**：每章结尾设置悬念（类型见 [reference.md](reference.md) 的"悬念钩子十三式"）
5. **控制节奏**：连续3章高压后必插入1章缓冲，连续2章平淡后必须提速

### 网文节奏自检

每章写完后检查：
- [ ] 本章有至少1个爽点或转折
- [ ] 章末有明确悬念钩子
- [ ] 没有连续超过200字纯景物描写
- [ ] 角色对话有个性化，不千人一面

---

## 阶段六：去AI味润色

正文生成后必须经过润色，详见 [de-ai-humanizer.md](de-ai-humanizer.md)。

### 核心禁令（快速检查）

- 禁用"仿佛/宛如/在那一刻"类比喻套句
- 禁用"不是……而是……"二分结构
- 禁止章末"他终于明白了一切"式总结感悟
- 禁止空洞景物描写开局
- 禁止套路化宣传腔（"前所未有的力量"、"惊天动地"）
- 用具体感官细节与动作动词替换上述表达

---

## 阶段七：状态归档

每章写完后立即更新状态文件，详见 [memory-tracker.md](memory-tracker.md)。

### 必须更新的文件

1. **角色状态表**：更新角色实时健康/心理/位置
2. **伏笔追踪表**：标记本章埋设/回收的伏笔
3. **道具持有表**：更新道具归属
4. **时间线**：追加本章事件

---

## 阶段八：逻辑审稿

每章或每卷完成后进行独立审稿，详见 [critic-qa.md](critic-qa.md)。

### 审稿角色设定

审稿Agent独立于创作Agent，**只审查不重写**，输出问题清单交回创作Agent修改。

### 核心检查项

- [ ] 战力一致性（无战力崩坏）
- [ ] 世界观一致性（无违背设定）
- [ ] 角色人设一致性（无OOC）
- [ ] 节奏合理性（无连续3章高压/连续2章平淡）
- [ ] 伏笔逻辑（埋设的伏笔有回收计划，已回收的无矛盾）
- [ ] 信息差合理性（角色获取信息路径合理）

## 快速使用指南

| 用户需求 | 执行动作 |
|---------|---------|
| "我想写一部小说" / "我有个故事想法" | 先执行 [reference.md](reference.md) 第四节"三层递进创意提炼"，提炼核心冲突和可执行设定 → 再执行阶段一建立设定库 |
| "帮我写第N章" | 检查状态文件 → 读章纲 → 拆场景卡 → 写正文 → 润色 → 逻辑审稿 → 归档 |
| "润色这段文字" | 直接执行阶段六去AI味润色 |
| "检查这章有没有问题" | 直接执行阶段八逻辑审稿 |
| "追踪伏笔" / "哪些伏笔没回收" | 直接执行阶段七状态归档，筛选未回收伏笔 |
| "规划下一卷" | 执行阶段二卷纲规划 |
| "这卷快写完了" / "卷末怎么处理" | 执行卷末收关流程（见下方） |
| "停了一段时间，要继续写" | 执行 [memory-tracker.md](memory-tracker.md) 断更恢复检查清单 |

## 卷末收关流程

当前卷剩余 2-3 章时触发：

```
1. 【伏笔清算】读取 state/foreshadowing.md，列出本卷所有"已埋设"伏笔
   - 本卷内必须回收的小伏笔 → 安排在最后1-2章回收
   - 跨卷大伏笔 → 安排一次"部分揭示"作为阶段性交代
   - 超过7个未回收 → 必须在本卷内回收至≤5个

2. 【节奏收束】检查本卷节奏（reference.md 节奏自检规则）
   - 卷末2章：必须有1章高潮爆发 + 1章余波收束
   - 最后1章章末：必须设置"下卷大钩子"（推荐类型10/11，见 reference.md 悬念钩子十三式）

3. 【状态归档】写完最后一章后：
   - 更新所有角色状态表（位置/健康/心理）
   - 更新伏笔追踪表（标记本卷已回收条目）
   - 追加本卷时间线事件

4. 【卷末审稿】执行 critic-qa.md 逻辑审稿，重点检查：
   - 本卷所有埋设的伏笔是否有回收计划
   - 卷内角色弧光是否有可见变化
   - 下卷大钩子是否足够有力
```
