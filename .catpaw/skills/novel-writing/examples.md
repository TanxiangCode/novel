# 使用示例

## 示例一：从零开始创建新小说项目

**用户**：我想写一部修仙小说，主角是被逐出宗门的弟子，要查师父死因。

**Agent 执行流程**：

### 步骤1：三层递进创意提炼

```
第一层·核心创意：
一个被诬陷弑师的少年弟子，伪装身份潜回仇人宗门，追查师父真正的死因。

第二层·核心冲突：
- 外部冲突：林远 vs 天衡宗权力核心（被阻挠查真相）
- 内部冲突：复仇欲望 vs 师父"莫怨恨"遗训
- 关系冲突：林远 vs 苏婉（林远要查真相，苏婉要藏真相）

第三层·可执行设定：
- 世界观关键词：修仙界、宗门体系、灵石经济、禁地秘境
- 主线目标：查清师父死亡真相
- 分卷目标：第一卷"入宗"——潜回宗门建立身份
- 核心伏笔：F-001玉佩刻字、F-002师父遗物中的药方
- 角色配置：林远(主角)、苏婉(亦敌亦友)、赵恒(失踪的同门)、宗主(幕后)
```

### 步骤2：创建设定库

创建文件结构：

```
novel-project/
├── settings/
│   ├── worldview.md
│   ├── characters/
│   │   ├── lin-yuan.md
│   │   ├── su-wan.md
│   │   └── zhao-heng.md
│   ├── timeline.md
│   └── factions.md
├── outline/
│   └── volume-1.md
├── chapters/
└── state/
    ├── character-state.md
    ├── foreshadowing.md
    └── inventory.md
```

### 步骤3：创建角色身份证

为 `settings/characters/lin-yuan.md` 填写：

```markdown
# 林远

## 基础信息
- 年龄/性别：17岁/男
- 身份/职业：原天衡宗外门弟子（被逐）
- 初始战力等级：练气三层
- 核心动机：查清师父死亡真相

## 气质锚点

### 视觉锚点
1. 总穿半旧的灰色麻布衫
2. 右手虎口有练剑磨出的老茧
3. 说话时习惯微微低头看地面

### 语言锚点
- 口头禅："嗯"（敷衍或思考时）
- 句式特征：短句为主，极少用成语
- 用词偏好：简洁、直接、不修饰
- 禁用表达：从不说"在下""不才"等自谦词

### 行为锚点
1. 紧张时搓右手拇指（旧伤位置）
2. 生气时反而变得安静、语速变慢
3. 每次说谎前会先喝一口水

## 人物弧光
- 起点：被逐出宗门、仇恨驱动、不信任任何人
- 转折触发点：发现师父可能不是被谋杀
- 终点：放下仇恨、找到真相但选择不同的路

## 关系网
| 角色 | 关系 | 当前态度 | 变化趋势 |
|------|------|---------|---------|
| 苏婉 | 同门旧识/亦敌亦友 | 警惕 | →不明 |
| 赵恒 | 师兄弟 | 担忧 | ↓恶化(失踪) |
| 宗主 | 仇人(怀疑) | 隐藏敌意 | - |

## 禁区
- 绝不伤害无辜
- 绝不食言（答应了就一定做到）
```

## 示例二：写一章正文

**用户**：帮我写第3章，林远在客栈遇到线人老王。

**Agent 执行流程**：

### 步骤1：读取上下文

读取以下文件：
- `settings/characters/lin-yuan.md`（角色身份证）
- `state/character-state.md`（角色当前状态）
- `state/foreshadowing.md`（伏笔追踪）
- `outline/volume-1.md`（卷纲）
- 前两章正文（恢复语感）

### 步骤2：拆场景卡

参考 `scene-card-crafter.md` 的示例，拆出3张场景卡（见该文件中的完整示例）。

### 步骤3：逐卡生成正文

基于场景卡 #1 生成第一段正文（此处给出风格示例）：

```
客栈大堂只点了两盏油灯。

林远找了靠墙的位置坐下，点了碗面。面端上来的时候已经凉了，他没在意，吃了几口，目光从碗沿上方扫过去——角落里那个老头还在，一壶茶喝了小半个时辰，没动几杯。

"天凉好个秋。"

他说这话的时候没看那老头，对着碗说的。角落里的茶杯顿了一下。林远继续吃面，但手已经从筷子换成了勺。不是刻意的，是练剑太久养成的习惯，空出来的手总得握点什么。
```

### 步骤4：去AI味润色

检查上述正文：
- 无"仿佛/宛如" ✓
- 无二分结构 ✓
- 无章末感悟 ✓
- 动作描写优先 ✓
- 角色锚点体现（搓手习惯、短句） ✓

### 步骤5：更新状态文件

更新 `state/character-state.md`：

```
| 林远 | 青云城·同福客栈 | 健康 | 警惕 | 获取密信线索 | 半块玉佩、短刀 | 第3章遇线人老王 |
```

更新 `state/foreshadowing.md`：

```
| F-005 | 老王倒茶时的特殊手势 | 第3章 | 第7章 | 已埋设 | - | 暗示其武功路数 |
| F-006 | 窗外黑衣人身份 | 第3章 | 第4章 | 已埋设 | - | 留下师门暗号树叶 |
```

### 步骤6：逻辑审稿

读取正文 + 设定 + 状态文件，执行 `critic-qa.md` 清单，输出审稿报告。

## 示例三：润色已有文字

**用户输入**：

> 阳光洒满大地，万物复苏。林远仿佛感受到了一股前所未有的力量在体内涌动，他的内心充满了激动。这一刻，他终于明白了修炼的真谛——不是追求力量，而是守护心中的信念。他望着远方的山峦，嘴角微微上扬，仿佛整个世界都安静了下来。

**Agent 执行**（基于 `de-ai-humanizer.md` 规则）：

逐条标记问题：
1. "阳光洒满大地，万物复苏" → 空洞景物开局
2. "仿佛感受到了一股前所未有的力量" → 套路比喻 + 宣传腔
3. "他的内心充满了激动" → 心理声明
4. "他终于明白了……不是……而是……" → 章末感悟 + 二分结构
5. "仿佛整个世界都安静了" → 套句

**改写结果**：

> 林远睁开眼。手心的老茧磨着膝盖，掌根发烫——像有人往骨头缝里灌了热水。他攥了两下拳，关节咔咔响，力道比昨天大了一圈。窗外传来鸟叫，他没听见，盯着自己的手看了很久。

## 示例五：断更恢复

**用户**：我停了两周没写，现在要继续写第8章。

**Agent**：执行 `memory-tracker.md` 中的断更恢复检查清单：

1. 读取角色状态表 → 确认每个角色位置/健康/心理
2. 读取伏笔追踪表 → 确认待回收伏笔
3. 读取时间线 → 确认当前时间节点
4. 读取道具持有表 → 确认关键道具
5. 读取涉及角色的 `settings/characters/[角色名].md` → 重新确认语言/行为锚点
6. 读取最近3章正文 → 恢复语感
7. 读取卷纲 → 确认第8章内容

输出摘要后开始创作。

- 🟡 警告：逻辑可疑，建议修改但可酌情保留
- 🟢 提示：优化建议，非强制

## 问题清单

### 问题 1 🔴
**类别**：世界观一致性
**位置**：场景二，林远离开客栈后的段落
**问题**：worldview.md 设定青云城城门"亥时关闭"，
但本章时间线已过亥时，林远仍能出城前往城郊密室，违背设定
**建议**：改为林远通过城墙缺口出城，或将密室位置改在城内

### 问题 2 🔴
**类别**：战力一致性
**位置**：场景三，林远与黑衣人对峙段落
**问题**：角色状态表显示林远"右臂刀伤未愈"，
但本章他用右臂格挡了黑衣人的剑击且无任何伤势反应
**建议**：改为林远用左臂格挡，或加一句"虎口被震得发麻，旧伤崩开了"

### 问题 3 🟡
**类别**：角色人设一致性（OOC）
**位置**：场景一，林远与老王的对话
**问题**：lin-yuan.md 语言锚点标注"从不说成语，用词简洁"，
但本章他说了"天网恢恢，疏而不漏"
**建议**：改为"跑不掉的" 或 "没用的"

### 问题 4 🟡
**类别**：去AI味执行情况
**位置**：场景三结尾段落
**问题**：章末仍保留"他终于明白了，有些人注定只能是过客"
命中去AI味高危禁用项（章末感悟式总结）
**建议**：退回润色阶段，改为行为暗示：
"他把信折好塞进怀里，吹灭了灯"

### 问题 5 🟢
**类别**：伏笔逻辑
**位置**：全章
**问题**：本章新埋设 F-005、F-006 后，未回收伏笔已达7个（触及上限）
当前未回收伏笔：F-001、F-002、F-004、F-005、F-006、F-007、F-008
**建议**：F-006（黑衣人身份）计划第4章回收，进度正常；
F-007（苏婉簪中毒药）距计划回收（第6章）仅剩3章，建议第4章加一处"部分揭示"
