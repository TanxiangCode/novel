# 详细参考资料

## 一、角色身份证（完整版）

角色身份证是防止人设崩塌的核心工具。每个主要角色必须建卡，配角可选。

### 完整模板

```markdown
# [角色名]

## 基础信息
- 年龄/性别/外貌：
- 身份/职业：
- 初始战力等级：
- 核心动机：[驱动角色一切行动的根本欲望，1句话]

## 气质锚点

### 视觉锚点（3个标志性视觉特征）
1. [特征1：如"总穿灰色旧袍"]
2. [特征2：如"左眉骨有斜疤"]
3. [特征3：如"看人时习惯眯左眼"]

### 语言锚点（说话方式）
- 口头禅/习惯用词：
- 句式特征：[短句多/长句多/反问多/省略主语]
- 用词偏好：[粗俗/文雅/简洁/啰嗦]
- 禁用表达：[这个角色绝对不会说的话]

### 行为锚点（3个标志性动作）
1. [动作1：如"紧张时搓右手拇指"]
2. [动作2：如"生气时反而变得安静"]
3. [动作3：如"每次说谎前先喝水"]

## 人物弧光
- 起点：[故事开始时的状态/信念]
- 转折触发点：[什么事件改变了他]
- 终点：[故事结束时的状态/信念]

## 关系网
| 角色 | 关系 | 当前态度 | 变化趋势 |
|------|------|---------|---------|
| [角色B] | [师徒/敌对/暗恋] | [信任/警惕/利用] | [↑加深/→不变/↓恶化] |

## 成长路线（战力/能力变化）
| 阶段 | 能力变化 | 触发条件 | 章节范围 |
|------|---------|---------|---------|
| 初始 | 练气三层 | - | 第1-5章 |
| 突破 | 练气五层 | 服用灵果 | 第5-8章 |
| ... | ... | ... | ... |

## 禁区（角色绝对不会做的事）
- [如"绝不伤害无辜儿童"]
- [如"绝不食言"]
```

### 名字遮盖测试

写完一段对话后，遮住角色名，仅看台词和行为：
- **能辨认出是谁** → 锚点足够鲜明，通过
- **无法区分** → 需强化语言/行为锚点

## 二、悬念钩子十三式

每章结尾使用其中一种（或组合），避免平铺直叙。

| 编号 | 钩子类型 | 说明 | 示例 |
|------|---------|------|------|
| 1 | **信息中断** | 关键信息说到一半被打断 | "老王刚要开口，门被踹开了" |
| 2 | **身份揭示** | 某角色身份出人意料 | "摘下面具，竟是失踪三年的师父" |
| 3 | **危机降临** | 突如其来的危险 | "屋顶裂开，一道剑光直劈而下" |
| 4 | **选择困境** | 角色面临两难选择 | "左边是苏婉的求救声，右边是密信所在的密室" |
| 5 | **信息反转** | 之前的认知被推翻 | "他以为老王是线人，但密信上写的名字是——掌柜" |
| 6 | **死亡悬念** | 角色生死不明 | "他跌下悬崖，下方是翻涌的怒江" |
| 7 | **时间紧迫** | 倒计时制造紧迫感 | "三日后丹田会碎裂，他必须在三天内找到解药" |
| 8 | **关系变化** | 关键关系突然改变 | "一直帮助他的人突然拔出了刀" |
| 9 | **伏笔推进** | 老伏笔突然有了新线索 | "那块玉佩上的刻字，他在一本古籍里找到了下半句" |
| 10 | **目标升级** | 原目标达成后发现更大目标 | "拿到密信才知，真正的敌人不是赵家，是整个宗门" |
| 11 | **视角切换** | 切到另一视角展示读者不知道的信息 | "与此同时，千里之外，一双眼睛正盯着这封信" |
| 12 | **环境突变** | 场景突然改变 | "雾散了，他发现自己站在一座从未见过的城门前" |
| 13 | **行为反常** | 角色做出反常行为暗示内情 | "苏婉接过药碗，第一次没有道谢" |

### 钩子使用规则

1. **避免连续2章用同一类型钩子**，需轮换
2. **钩子必须在下一章3段内回应**，不能"钩完就忘"
3. **网文向**：推荐优先使用1、3、5、6、8类型（刺激性最强）
4. **通用向**：推荐优先使用2、4、5、9、10类型（信息驱动型）

## 三、节奏模板

### 网文爽点节奏模板（每卷12章为例）

```
第1章：引入冲突 + 钩子（类型1/3）
第2章：困境升级 + 钩子（类型4/7）
第3章：小爽点（逆境中反击） + 钩子（类型5/9）
第4章：缓冲/日常 + 暗线推进 + 钩子（类型11/13）
第5章：新冲突引入 + 钩子（类型3/10）
第6章：压抑/蓄力 + 钩子（类型6/7）
第7章：大爽点（高潮爆发/打脸/逆转） + 钩子（类型2/8）
第8章：余波/关系变化 + 钩子（类型4/13）
第9章：伏笔回收 + 新线索 + 钩子（类型9/10）
第10章：冲突再升级 + 钩子（类型5/12）
第11章：危机顶点 + 钩子（类型6/7）
第12章：卷末高潮 + 收束 + 新卷大钩子（类型10/11）
```

### 通用小说节奏模板

```
起（第1-2章）：引入角色/世界/冲突
承（第3-5章）：冲突发展/角色成长/伏笔埋设
转（第6-9章）：转折/反转/高潮
合（第10-12章）：收束/伏笔回收/新悬念
```

### 节奏自检规则

| 检查项 | 标准 |
|-------|------|
| 连续高压章数 | ≤3章，第4章必须有缓冲 |
| 连续平淡章数 | ≤2章，第3章必须提速 |
| 爽点间距（网文向） | 每1-2章至少1个小爽点 |
| 钩子轮换 | 不连续2章用同类型钩子 |
| 每章推进度 | 至少推进1个主线信息或1个伏笔 |

## 四、三层递进式创意提炼

用于新项目启动时，从模糊想法到可执行设定。

### 第一层：核心创意（1句话）

回答：这个故事最吸引人的是什么？

```
模板：一个[什么样的人]在[什么困境]中，为了[什么目标]，[做了什么出人意料的事]。

示例：一个被逐出宗门的废柴少年，为了查出师父死亡的真相，伪装身份潜回了仇人门下。
```

### 第二层：核心冲突（3要素）

```
1. 外部冲突：[角色 vs 什么外部力量]
   示例：林远 vs 宗门权力体系（查真相被阻止）

2. 内部冲突：[角色内心矛盾]
   示例：林远想复仇 vs 师父遗言"不要怨恨"

3. 关系冲突：[角色间核心矛盾]
   示例：林远 vs 苏婉（一个查真相一个藏真相，但互相依赖）
```

### 第三层：可执行设定

```
世界观关键词：[3-5个设定关键词]
主线目标：[主角的终极目标]
分卷目标：[每卷要解决的子问题]
核心伏笔：[2-3个贯穿全书的大伏笔]
角色配置：[主角1 + 核心配角2-3 + 反派1-2]
```

## 五、多视角审稿模式

当小说采用多POV时，除常规审稿外增加以下检查：

- [ ] 不同POV角色的内心独白风格是否有区分
- [ ] 同一事件在不同POV下的描述是否一致（事实层面一致，感受可不同）
- [ ] 读者视角的信息量是否合理（不能A视角剧透B视角的悬念）
- [ ] POV切换频率是否合理（不频繁跳切导致混乱）
- [ ] 各POV角色的戏份比例是否符合角色重要性

## 六、多 Agent 协作流程说明

本技能可拆分为多个 Agent 角色协作执行：

| Agent | 职责 | 对应阶段 |
|-------|------|---------|
| **Architect** | 设定建库、卷纲规划 | 阶段一、二 |
| **Outliner** | 章纲拆解、场景卡制作 | 阶段三、四 |
| **Writer** | 正文生成 | 阶段五 |
| **Humanizer** | 去AI味润色 | 阶段六 |
| **Updater** | 状态归档（伏笔/角色/道具更新） | 阶段七 |
| **Critic** | 逻辑审稿质检 | 阶段八 |

### 协作流程

```
Architect → Outliner → Writer → Humanizer → Updater → Critic
                                                          │
                                              有问题？─→ 退回 Writer 修复
                                              无问题  ─→ 进入下一章
```

单用户使用时，一个Agent依次扮演所有角色即可，关键是**每个阶段的输出文件要落盘**，下一阶段读取文件而非依赖记忆。
