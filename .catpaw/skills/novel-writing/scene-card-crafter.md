# 场景卡拆解方法

## 使用场景

章纲确定后、正文生成前。将一章（约3000字）拆成2-3个场景卡，每卡约800-1500字。逐卡生成正文后拼接成完整章节。

---

## 一、为什么要拆场景卡

1. **控制节奏**：每个场景有明确的情绪走向，避免通篇平铺直叙
2. **管理信息差**：明确每个场景中"谁知道什么"，制造悬念和反转
3. **防止AI味**：逐场景聚焦具体动作和对话，减少空洞大段描写
4. **保证连贯性**：前后场景的伏笔和状态有据可查

---

## 二、场景卡模板

每张场景卡必须包含以下字段：

```
═══════════════════════════════════════
场景卡 #[N]
═══════════════════════════════════════

POV（视角角色）：[角色名]
地点/时间：[具体地点] · [时间]
出场人物：[在场所有角色]

【角色核心目标】
[本场景中POV角色想要达成什么]
例：林远想从老王口中套出密信的下落

【阻碍与对抗】
[什么阻止了目标达成]
例：老王生性多疑，拒不开口；窗外有人监视

【信息差】
- POV知道：[视角角色掌握的信息]
- 对方知道：[对方掌握的信息]
- 双方都不知道：[双方都不掌握的隐藏信息]
- 读者知道：[只有读者知道的上帝视角信息（如有）]

【情绪走向】
从[X] → 到[Y]
例：从试探 → 到紧张 → 到妥协

【关键动作/对话】
[本场景中必须发生的1-2个关键事件]
例：林远亮出半块玉佩，老王态度突变

【伏笔操作】
- 埋设：[在本场景埋下的新伏笔]
- 回收：[本场景回收的已有伏笔]
- 推进：[本场景推进的已有伏笔]

【章末钩子】（仅最后一个场景卡需要）
[本场景结束时的悬念/反转]
═══════════════════════════════════════
```

---

## 三、拆解流程

```
1. 读取章纲，确认本章核心目标
2. 确定场景数量：
   - 纯对话场景：1个场景卡
   - 动作+对话场景：2个场景卡
   - 多地点/多视角切换：3个场景卡
3. 逐张填写场景卡
4. 检查场景间衔接：
   a. 时间连贯（前场景结束→后场景开始的时间）
   b. 空间转换合理（角色移动路径）
   c. 情绪递进（不是同一情绪反复）
5. 确认章末钩子类型（见 reference.md "悬念钩子十三式"）
```

## 四、场景卡拆解示例

### 章纲

```
第3章：密信
- 林远在客栈遇到神秘老者老王
- 通过对话试探，老王透露密信线索
- 章末：林远发现窗外有人在监视他
```

### 拆解结果

**场景卡 #1**
```
POV：林远
地点/时间：青云城·同福客栈·大堂 · 夜
出场人物：林远、老王、客栈伙计（背景）

角色核心目标：林远想从老王口中套出密信的下落
阻碍与对抗：老王伪装成普通旅客，不露破绽；林远不确定他是否就是线人
信息差：
  - 林远知道：自己来青云城找密信，接头人暗号是"天凉好个秋"
  - 老王知道：自己就是接头人，但不确定林远身份
  - 双方都不知道：窗外黑衣人正在监视
  - 读者知道：（无）

情绪走向：从试探 → 到确认身份
关键动作：林远说出暗号"天凉好个秋"，老王眼神变化，倒茶手势变了
伏笔操作：埋设F-005（老王倒茶时的特殊手势，暗示其武功路数）
```

**场景卡 #2**
```
POV：林远
地点/时间：同福客栈·大堂 · 夜（接场景一）
出场人物：林远、老王

角色核心目标：获取密信具体位置
阻碍与对抗：老王要求林远先证明身份，亮出信物
信息差：
  - 林远知道：自己有半块玉佩
  - 老王知道：接头信物是完整的玉佩（需两半拼合）
  - 双方都不知道：另一半玉佩在赵恒手中
  - 读者知道：赵恒已失踪（第2章伏笔F-003）

情绪走向：从协商 → 到僵持 → 到妥协
关键动作：林远亮出半块玉佩，老王面色一变，说"还差一半"
伏笔操作：推进F-003（赵恒失踪），暗示另一半玉佩与赵恒有关
```

**场景卡 #3**
```
POV：林远
地点/时间：同福客栈·二楼客房 · 深夜
出场人物：林远

角色核心目标：思考下一步行动（去找赵恒？）
阻碍与对抗：发现窗外有人影闪过
信息差：
  - 林远知道：只有半块玉佩，需要找到赵恒
  - 监视者知道：林远今夜见了老王
  - 双方都不知道：对方的具体身份

情绪走向：从沉思 → 到警觉
关键动作：林远吹灭蜡烛，摸向枕下短刀，窗外人影消失
伏笔操作：埋设F-006（黑衣人的身份悬念）
章末钩子：发现窗台上留了一片树叶——那是他师门的紧急暗号
（钩子类型：身份揭示型——暗示师门有人在此）
```

## 五、场景卡质检

拆解完成后检查：

- [ ] 每张卡有明确角色目标
- [ ] 每张卡的阻碍与目标直接对立
- [ ] 信息差字段已填写（不能全填"无")
- [ ] 情绪走向有变化（不是从平静到平静）
- [ ] 场景间时间空间连贯
- [ ] 伏笔操作有记录（埋设/回收/推进）
- [ ] 最后一张卡有章末钩子

### 字数校验

| 场景卡数量 | 预计章节总字数 | 是否合理 |
|-----------|-------------|---------|
| 2张卡 | 1600-3000字 | ✓ 标准短章 |
| 3张卡 | 2400-4500字 | ✓ 标准章 |
| 4张卡 | 3200-6000字 | ✓ 长章（节奏缓慢时使用） |

> **生成完正文后**：统计实际字数，若低于场景卡下限的80%，说明场景写得过于省略，需补充细节；若超过场景卡上限的120%，检查是否有冗余段落，执行一轮删减。
