# 去AI味润色规则

## 使用场景

正文生成后、归档前执行。逐段扫描全文，命中以下任意规则即标记并改写。

---

## 一、绝对禁用清单（命中即改）

### 1. 套路化比喻

| 禁用表达 | 改写方向 |
|---------|---------|
| 仿佛/宛如/好像/犹如 | 删掉比喻，改用直接感官描写 |
| 在那一刻 | 删掉，用动作本身暗示时间 |
| 宛如星辰般的眼眸 | 改写为具体特征："眼睛很亮，盯着人看时像在发问" |
| 如同暴风雨席卷而来 | 改写为具体动作："风把门撞开，纸飞了一地" |

### 2. 二分结构句式

| 禁用表达 | 改写方向 |
|---------|---------|
| 不是A，而是B | 只保留B的正面描写 |
| 这不仅仅是A，更是B | 删掉前半句 |
| 与其说A，不如说B | 直接说B |

### 3. 章末总结感悟

| 禁用表达 | 改写方向 |
|---------|---------|
| 他终于明白了一切 | 改用动作暗示：他沉默了很久，把信折好塞进口袋 |
| 此刻他懂得了生命的意义 | 删掉，让读者自己感受 |
| 经历这一切后，他变了 | 用行为展现变化，不声明变化 |
| 望着远方，他心中已有答案 | 删掉或改为具体行为 |

### 4. 空洞景物开局

| 问题 | 改写方向 |
|------|---------|
| 用大段景物描写开章 | 改用角色动作/对话开场，景物随视角移动穿插 |
| "阳光洒满大地，万物复苏" | 改为有功能的环境描写：与角色情绪或剧情推进相关 |

### 5. 套路化宣传腔

| 禁用表达 | 改写方向 |
|---------|---------|
| 前所未有的力量 | 改为具体感受："手腕发麻，虎口裂开一条缝" |
| 惊天动地 | 删掉或改为具体效果描写 |
| 震撼了整个X界 | 删掉，改为旁观者的具体反应 |
| 传说级别的存在 | 用具体事迹替代标签 |

## 二、AI味高频特征扫描

### 6. 排比三连

**问题**：AI倾向生成三段排比句制造气势。
**改写**：删减为1-2句，或改为递进而非并列。

### 7. 过度形容词堆砌

**问题**："深邃而幽暗的、弥漫着淡淡腐朽气息的地下室"
**改写**："地下室很暗，有股腐味。"

### 8. "他的心中涌起一股X"

**改写**：用身体反应替代心理声明。怒→攥拳/咬后槽牙/呼吸变粗；惧→手抖/后退半步/声音发紧。

### 9. 过度解释

**问题**：AI倾向在动作后加一句解释说明动机。
**改写**：信任读者能从上下文推断动机，删掉解释。

### 10. 对话过于文雅

**问题**：所有角色说话方式相同，用词偏书面。
**改写**：区分角色语言锚点——粗人说粗话，少年用短句急促，老人用长句啰嗦。

---

## 三、替换原则

### 核心原则：用身体替换心理，用动作替换形容，用细节替换概括

| AI味写法 | 人类写法 |
|---------|---------|
| 他感到十分愤怒 | 他一拳砸在桌上，茶杯跳起来 |
| 她的内心充满悲伤 | 她把脸埋进膝盖，肩膀抖了好一阵 |
| 这个地方非常恐怖 | 墙上有干涸的褐色痕迹，角落里堆着几团衣服 |
| 他是一个强大的人 | 他单手把铁棍掰弯了 |

---

## 四、润色工作流

```
1. 通读全文，标记所有命中禁用清单的句子
2. 逐条改写：
   a. 删除套话比喻，替换为感官细节
   b. 拆解二分结构，只留核心信息
   c. 章末感悟改为行为暗示
   d. 景物开局改为动作开局
3. 二次通读，检查改写后是否自然
4. 名字遮盖测试：遮住角色名，仅看对话和行为，
   能否辨认出是哪个角色？不能则需强化语言/行为锚点
```

## 五、网文去AI化负面清单速查（20+条）

> **执行顺序**：先扫 🔴 高危项（1-5条），命中即改写，再扫 🟡 中危项（6-20条）。

**🔴 高危（命中率高、AI味最重，优先处理）**
- [ ] 无"仿佛/宛如/在那一刻"
- [ ] 无"不是A而是B"二分结构
- [ ] 无章末"他终于明白了"式感悟
- [ ] 无空洞景物开局
- [ ] 无"前所未有的力量"式宣传腔

**🟡 中危（次优先处理）**
- [ ] 无三连排比
- [ ] 无形容词堆砌链（超过3个形容词连用）
- [ ] 无"心中涌起一股X"心理声明
- [ ] 无过度解释动机
- [ ] 角色对话有个性区分度
- [ ] 动作描写优先于心理描写
- [ ] 感官细节优先于形容词
- [ ] 具体数字优先于"很多/许多"
- [ ] 短句与长句交替（不全是匀速句）
- [ ] 无连续超过200字纯环境描写
- [ ] 章末有动作/对话而非感悟
- [ ] 无"他/她"指代不清的段落
- [ ] 无突然跳出视角的叙述
- [ ] 无"不知不觉"等模糊时间表达
- [ ] 无"仿佛整个世界都安静了"式套句
